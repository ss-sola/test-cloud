# 项目目录 API

## 范围

接口仅访问 `apps/system-service/public/workflow/` 当前层级的工作流 JSON。目录固定于服务项目根目录，不接受任意路径，不依赖启动 `cwd`，不提供删除、移动、子目录浏览或执行接口。此目录是已确认的后端文件存储限定例外；其他业务数据及执行状态不允许落盘。

基础路径为 `/api/workflow-directory`；部署配置全局前缀时与其他后端接口一致。当前管理台沿用固定同源 `/api` 路径。响应 `Cache-Control: no-store`，统一使用 `{code,message,data}`；成功 `code: 200`。保存仅接受 `application/json`，跨来源浏览器请求被拒绝。请求正文不会进入公共访问日志。

## 接口清单

| 方法 | 路径 | 用途 |
|---|---|---|
| GET | `/list` | 列出固定目录当前层级的 JSON 文件 |
| GET | `/document?filename=...` | 读取并校验一份工作流，返回内容和文件版本 |
| POST | `/document` | 以完整快照新建或按版本覆盖一份工作流 |

### 文件列表

请求不需要参数，成功 `data`：

```json
{
  "directory": "public/workflow",
  "list": [{ "name": "周报生成.json" }]
}
```

只列普通文件，不列目录或链接。目录条目超过 1000 时明确报错，不静默截断；固定目录尚不存在时返回空列表，后续显式保存时创建。

### 读取

`filename` 为 query 参数，必须是最多 120 个 UTF-16 字符、255 个 UTF-8 字节的单段 `.json` 文件名（后缀不区分大小写）。拒绝以点开头、含 `.tmp.`、路径分隔、控制／格式字符、孤立代理项和 Windows 保留设备名；主干不能全是点或带首尾空白。不要传 `public/workflow/` 前缀。

成功 `data`：

```json
{
  "filename": "周报生成.json",
  "text": "{\"version\":1,\"id\":\"workflow-example\",\"name\":\"工作流示例\",\"nodes\":[],\"edges\":[],\"viewport\":{\"x\":24,\"y\":24,\"zoom\":1}}",
  "revision": "0123456789abcdef0123456789abcdef0123456789abcdef0123456789abcdef"
}
```

`revision` 是磁盘原始文件字节的 SHA-256，包含其原有格式和空白；示例值仅说明格式。`text` 是服务端校验并按工作流白名单规范化的内容，已重置已知 `localConfig` 节点配置，不包含开始节点凭据。读取不改写原文件、不运行节点；前端仍以新副本导入，不覆盖当前流程。

### 保存

三个字段全部必传：

```json
{
  "filename": "工作流示例.json",
  "text": "{\"version\":1,\"id\":\"workflow-example\",\"name\":\"工作流示例\",\"nodes\":[],\"edges\":[],\"viewport\":{\"x\":24,\"y\":24,\"zoom\":1}}",
  "expectedRevision": null
}
```

- `text` 必须是完整工作流文档 JSON 字符串，不是图库内部 JSON，也不是节点补丁。
- `expectedRevision: null` 只允许新建；目标已存在则返回 409，绝不隐式覆盖。
- 覆盖时传当前文件的 64 位小写十六进制 SHA-256，必须与磁盘文件一致；缺失该字段、大小写不符、未知字段或类型错误均拒绝。
- 服务端限制文本为 4 MiB UTF-8，并重新校验版本、节点、连线及预算，规范化清除结果、运行状态、历史和已知本地凭据配置。
- 新建使用不覆盖已有目标的原子提交；覆盖使用临时文件和原子替换。协作服务进程使用目录临时锁，同一实例亦串行处理。失败不能将旧文件改成半份内容。

成功 `data` 为 `{ "filename": "工作流示例.json", "revision": "新文件的 SHA-256" }`。

## 版本冲突闭环

同名或版本变化时 HTTP 409 的 `revision` 位于响应**顶层**：

```json
{
  "code": 409,
  "message": "文件已存在或版本已变化",
  "revision": "0123456789abcdef0123456789abcdef0123456789abcdef0123456789abcdef"
}
```

未关联文件首次以 null 尝试新建；仅在响应含有效版本时向用户确认覆盖。已关联文件的 Ctrl+S 直接提交已知 expectedRevision，不再次确认，也不在冲突时自动改用新版本。确认后用同一文件名和内容快照、携带该版本重试一次，第二次冲突直接报错，不自动再次确认或无限重试。文件被删除时版本可为 null；目录被其他进程占用等冲突不提供可覆盖版本，此时不应弹出覆盖确认，刷新后重试。

所有保存目标固定，不会将界面切换后的流程写到原文件名。取消确认不再发送保存请求。取消 HTTP 等待、超时或断线不能保证撤销服务端写入，结果可能未知，应先刷新目录确认，不能把网络错误当作文件一定没有写入。

## 错误与公开边界

| HTTP 状态 | 含义 |
|---|---|
| 400 | 文件名、DTO、工作流格式或版本不合法 |
| 403 | 不允许的来源或文件访问边界 |
| 404 | 文件或接口不存在 |
| 405 / 415 | 方法或内容类型不支持 |
| 409 | 文件版本变化、目标已存在、目录被其他写入者占用或 Windows 文件占用（EPERM/EBUSY/EACCES）；占用类不带 revision |
| 413 | 文档、请求体或目录预算超限 |
| 5xx | 文件系统不可用、占用或提交失败等受控错误 |

内部错误不回显磁盘路径、正文、凭据或堆栈。临时文件和临时锁失败后会清理自己的文件；进程崩溃遗留锁须确认不存在活跃写入后人工清理，不能直接抢占。

**目录文件是明文公开资源**，可通过 `/public/workflow/<文件名>` 读取；该路径直接映射固定源目录，不等待 `dist` 复制。不要保存私有业务文本或将密钥嵌入普通文本节点。此接口不新增账号模型，不等于为公开部署提供了完整的访问控制；上线时应沿用现有网关和可信访问边界。部署位置、锁恢复和测试入口见 [执行与存储](./执行与存储.md#项目目录读写)。
