# 工作流模块

工作流是 `system-service` 前端的可扩展、有类型数据流工作台。首批节点使用既有 JSON/ENV 内容对比接口；工作流文档保存在浏览器，运行结果只在当前页面内存中。页面入口为 `/public/index.html#workflow`，原有 JSON／ENV 独立页面继续保留。

- [产品与交互](./产品与交互.md)：用户路径、首批节点、画布与多流程交互、本期范围。
- [节点扩展](./节点扩展.md)：独立文档协议、类型与节点版本注册、执行器和 UI 渲染契约、自定义节点示例。
- [执行与存储](./执行与存储.md)：手动 DAG 执行、停止和运行锁、保存/恢复、预算与隐私、构建入口。

已有对比接口及响应结构见 [内容对比 API](../content-compare/API.md)；产品实施背景与阶段记录见 [工作流计划](../plan/workflow-canvas-2026-10-20.md)。
