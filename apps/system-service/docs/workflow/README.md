# 工作流模块

工作流是 `system-service` 的可扩展、有类型数据流工作台。浏览器保留自动草稿，允许显式读写项目固定 `public/workflow` 的 JSON；运行结果仍只在当前页面内存中。页面入口为 `/public/index.html#workflow`。

- [产品与交互](./产品与交互.md)：用户路径、首批节点、画布与多流程交互、本期范围。
- [节点扩展](./节点扩展.md)：独立文档协议、类型与节点版本注册、执行器和 UI 渲染契约、自定义节点示例。
- [执行与存储](./执行与存储.md)：手动 DAG 执行、从节点运行与结果失效、停止和运行锁、保存/恢复、预算与隐私、构建入口。
- [项目目录 API](./API.md)：固定目录列表、读取、保存、版本冲突与公开访问边界。
- [原子能力与周报组合](../workflow-capabilities/README.md)：通用 JSON 取值/合并、日期/模板、语义数据类型与节点版本升级、独立 GitHub/AI/飞书能力、文本展示及本地 OpenAPI。

已有对比接口及响应结构见 [内容对比 API](../content-compare/API.md)；产品实施背景与阶段记录见 [工作流计划](../plan/workflow-canvas-2026-10-20.md)。
