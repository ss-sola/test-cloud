# 产品与交互

## 定位与本期范围

用户已确认将工作流作为**通用、可扩展的有类型数据流画布**，而非只为对比功能定制的连线页面。首批内置节点由 `public/js/workflow-nodes.js` 注册：

| 节点 | 输入 | 输出 | 用途 |
| --- | --- | --- | --- |
| 开始 `start@1` | 无 | `trigger: trigger`（control，值为 `true`） | 唯一显式执行入口 |
| 文本 `text@1` | 无；节点配置中的原文 | `text: text`（data） | 被动提供本次执行使用的文本；与原子能力共用声明式表单（占满节点的文本域与字数提示） |
| JSON 对比 `json-compare@1` | 可选 `trigger: trigger`（control）；必需 `a: text`、`b: text`（data） | `diff: diff`（data） | 将两侧原文送到已有 JSON 对比接口 |
| ENV 对比 `env-compare@1` | 可选 `trigger: trigger`（control）；必需 `a: text`、`b: text`（data） | `diff: diff`（data） | 将两侧原文送到已有 ENV 对比接口 |
| 对比结果 `diff-result@1` | 必需 `diff: diff`（data） | `diff: diff`（data） | 在节点内展示结构化结果，并原样向下游转发 |

典型流向是开始节点的“开始”控制输出连接对比节点的“启动”输入，两个文本节点分别连接对比节点的 A/B 数据输入，再将 `diff` 数据输出连接结果节点；结果节点依赖数据边继续激活，不需要单独的控制输入。开始节点可以触发多个处理分支，但每份流程最多一个开始节点，每个输入端口至多一个来源。端口须同时匹配 `dataType` 和 `kind`，控制信号不混入对比的 A/B 业务数据。结果节点约定展示 A/B 对照、高亮分段、统计和可折叠差异树，不另提供 A/B 文本输出。A/B 文本窗格在各自滚动条旁提供固定差异概览轨道：新增绿色、删除红色、修改青色，按各侧全文的相对行位置分布，连续同类差异合并。轨道不随正文滚动、不阻挡鼠标，也不提供点击跳转；尺寸变化后保持相对位置。更新、失败或清空结果时清除旧标记，JSON／ENV 共用相同的 diff.segments 渲染规则。`diff` 结果形状与后端协议见 [内容对比 API](../content-compare/API.md)；工作流对比适配只调用已有 `POST /api/content-compare/json` 与 `/api/content-compare/env`，**没有新增 API**。

## 原子能力与周报组合

原五类节点之外，增加日期范围、JSON 输入、JSON 解析、JSON 取值、JSON 合并、文本模板、GitHub 提交抓取、AI 文本生成、文本/Markdown 结果、飞书查找行、飞书单元格写入十一类可复用节点。处理节点均有可选 control/trigger 输入，只有被动输入时也可直接从开始触发。所有能力保持单一职责；日期范围、提交数组、匹配条件、表格坐标、单元格矩阵使用 json 的语义子类型，错连在连线时即被拒绝。详细输入/输出、配置与版本见 [节点与组合](../workflow-capabilities/节点与组合.md)。

“周报”不是一个内置业务节点。空画布样例一次插入开始、日期、抓取、JSON 合并、提示词模板、AI、文本结果七节点七边，可一步撤销，不自动请求或发布。抓取结果与日期范围经 JSON 合并后作为模板的 context 传入，不再按标题过滤。用户填写仓库/人员并配置凭据后，运行分别调用抓取与 AI 独立接口，不调用旧周报 jobs；原周报页面不变。

数据筛选节点已移除。旧草稿中的该节点及连线仍可查看和导出，但作为未知节点阻止整图运行；用户需删除并手动重连，或重新导入新版样例，不自动迁移。

JSON 与模板内容允许保存未完成草稿，运行前 flush，执行时解析/校验；字段错误可见且不会悄悄使用旧值。文本结果支持原文、安全 Markdown、格式化 JSON、复制和完整下载，可直接连接 JSON 数据输入（与文本输入二选一），不能用 diff 结果节点替代。受控远程节点只引用 Token 配置，不把凭据保存到节点或输出；AI 会将提示词包含的数据发送给所配置提供方。

飞书行查找仅在显式范围内判断唯一，写入只接明确坐标和矩阵，不内置上周/姓名/C:G 规则；写入节点用 maxRows（默认 1）与 expectedColumns 约束行列，超出即拒绝、不截断。每次写入前单独确认实际目标、范围和内容，确认不持久化、不导出、不能通过导入预设，等待确认不计入请求超时；停止等待不等于撤销远端已经发生的写入。接口、安全边界和预算见 [原子能力接口](../workflow-capabilities/API.md)与[安全说明](../workflow-capabilities/安全与执行边界.md)。

AI 文本、飞书写入与 JSON 取值节点有 v2 新版本。旧流程中的 v1 节点按原规则继续运行，节点上显示“旧版本 v1”提示和“升级到 v2”按钮；升级按迁移规则改写配置，是一次可撤销编辑，不会自动发生。

## 外观与节点库

“项目目录”和“节点库”位于系统左侧栏顶部、品牌区与其他页面菜单之间，只在工作流路由显示。点击入口展开对应内容，再次点击收起，两个面板互斥。每个面板仅显示搜索框和可折叠文件夹树，不显示标题栏、关闭按钮、数量、空态说明或帮助文案。切换不销毁 DOM，因此查询、折叠和画布视口保留；Escape 先清空当前查询，再次按下收起面板并将焦点交还入口。

工作流取消页面最大宽度与外层留白，工具栏单行滚动，画布填满顶部栏和工具栏之外的剩余视口。操作提示以不占布局、不拦截指针的浮层显示，出现或清空时不能移动画布和端口。左侧栏折叠时保留入口图标，内容作为邻接浮层显示；窄屏沿用系统导航抽屉，不挤占主画布。离开工作流后恢复其他页面原有尺寸和主题。

“项目目录”固定使用 `apps/system-service/public/workflow/`，打开导航或手动重新展开文件夹时刷新当前层级 JSON 文件，不浏览其他目录或子目录。搜索只在已加载的文件名中按 NFKC 规范化、大小写不敏感和多词全部匹配筛选，不发请求；搜索临时展开根目录，清空后恢复搜索前状态。点击文件按既有规则校验并创建新流程副本，不覆盖已有流程、不自动运行；操作失败复用页面已有错误出口。

顶部基础操作为名称、新建、导入、导出、运行、停止；按用户后续确认，额外保留“添加区域”按钮。`Ctrl+S`／`Command+S` 直接保存项目文件，不调用浏览器“保存网页”，也不等同于下载导出：项目目录打开的流程保存回原文件，新建和外部导入首次按流程名称生成安全的 `.json` 文件名。保存会先提交节点输入、未失焦名称和视口；已关联文件携带当前版本直接保存，不重复确认，发生外部版本冲突则拒绝覆盖。仅首次保存撞到未关联同名文件时确认覆盖。

文件关联保留在本浏览器，切换或刷新后仍能定位原文件；改流程显示名称不会隐式重命名或删除源文件。目录再次打开同文件同版本时复用已有草稿，外部版本变化则导入新的原名副本，旧草稿不删除。目录面板继续只提供搜索与读取，不增加保存按钮或说明；localStorage 自动草稿与 JSON 下载导出保持独立。

后端仅对这个已确认目录提供工作流 JSON 读写，作为项目不持久化业务数据规则的限定例外，不保存运行结果、任务状态或开始节点凭据。文件以明文保存，并可通过 `/public/workflow/<文件名>` 公开访问，禁止保存私有数据或在其他节点文本中写入密钥；其他环境仍可使用原有 JSON 导入导出。接口见 [项目目录 API](./API.md)，实现和部署边界见 [执行与存储](./执行与存储.md#项目目录读写)。

工作流采用根 `DESIGN.md` 中的暗黑局部例外，包含画布、工具栏、节点、差异结果和当前路由的管理台壳层。离开 `#workflow` 后恢复其他页面的浅色风格，不保存全站主题状态。图元与控件统一使用 `--wf-*` 令牌，状态文字和差异标签仍保留。

节点库按注册定义的 category 展示为可折叠文件夹；`/` 分隔的分类支持多级目录，叶子只显示节点名称并保留点击添加和拖入画布。搜索支持名称、类型、分类和端口元信息，按 NFKC、大小写不敏感和多词“全部匹配”过滤，不搜索工作流输入原文。搜索临时展开根目录和匹配分类，清空后恢复此前折叠状态；不显示匹配数或额外空态。查询与折叠仅保留在当前视图，切换流程仍保留，刷新后重置，不进入文档或撤销历史，也不发请求。运行时可继续搜索和折叠，节点添加/拖入仍受运行锁限制。

## 连线选择与流光

连线通过节点端口拖动创建，不再提供键盘连线表单或连线列表。线条不显示文字标签或箭头；源端口和目标端口仍决定数据方向，业务文档及执行规则不变。节点内的端口名称继续保留。

- 点击线条直接选中，Ctrl／Command 点击可多选；选中的线原地暂停流光并增强描边和光晕，未选中的线继续流动，取消选中后从暂停处恢复。可用 Delete 移除，并支持快捷键撤销重做。运行时仍可选中查看和暂停该线的视觉效果，但不能删除。
- 源端和目标端都连接端口圆心，使用中心 anchor 与 anchor connectionPoint，不按圆的外边缘裁剪，也不依赖像素偏移补偿；缩放、平移及节点尺寸变化后仍按实际圆心计算。
- 透明宽命中路径与光效分离，缩放后仍保持可点击宽度；光晕、底线和光点不接收指针，不遮挡节点输入、端口拖线或 Ctrl 空白平移。Tab 聚焦连线后可选中，Enter／Space 操作及 Delete 删除仍可用，可访问名称与选择状态不作为可见标签展示。
- 少量光点通过浏览器原生 CSS 路径动画（offset-path / offset-distance）沿实际连接曲线循环，随节点移动和尺寸调整同步。每条线有独立播放状态，不使用逐帧 JavaScript，不将光效写入工作流文档或历史；持续流动仅表示视觉数据方向，不表示后端正在执行，也不会自动发起请求。
- 工作流切换到隐藏状态、页面不可见或系统开启 prefers-reduced-motion 时，隐藏流动光点并暂停对应路径动画；恢复可见且允许动效后，只有未选中的线继续流动。静态连线和选中反馈始终保留，销毁视图时解除监听和观察器。

## 区域标注

- 顶部工具栏“添加区域”按钮在当前视口中央添加“区域”（区域不出现在节点库及其搜索中，运行中按钮禁用）：一个几乎透明的有色方框，只有名称（标题栏中的节点名称），没有描述、没有连接点，不参与运行、不显示运行状态，也不会因编辑它而让已有运行结果过期。用于圈出一组节点的范围，名称标签贴在方框左上角外侧，绘制在画布之上的独立图层中，始终压在节点和连线上方（宽度随名称伸展），可像普通节点一样拖动标签左侧的类型字样移动、选中后调整尺寸、复制、删除和撤销，并随流程保存与导入导出。
- 颜色取自固定的 10 色调色板，方框按约 10% 透明度铺底、半透明边框；名称所在标题栏为不透明底色（区域色混入表面色），压在连线上也能看清。新建或复制区域时优先选用当前流程中尚未被区域使用的颜色；10 色都已使用时取使用次数最少的颜色。同批复制的多个区域之间也互不撞色。
- 画布缩小时，区域名称标签保持 100% 时的屏幕尺寸，远景下仍能看清；画布放大时随之放大。
- 区域位于连线上方、节点下方（连线透过半透明底色仍可见，并可穿过区域空白处点击选中）；方框内部（含 X6 承载层）不接收鼠标，在区域内按下左键是框选、Ctrl+左键是平移画布，都不会拖动区域；只有名称标签可操作。框选需完整包含区域才会选中它，框选区域内的节点不会把区域一起选中拖走。
- 区域尺寸上限为 10000（普通节点仍为 2400），以便圈住整条处理链路。

## 运行中节点流星

- 节点状态为“运行中”时，节点四个角各发出一颗彩色流星，顺时针沿所在边飞向下一个角（左上→右上→右下→左下→左上）；四颗同步出发、同步抵达，循环播放。
- 每颗流星是一个整体元素：尾部为从透明连续渐变到青白的楔形，头部为带光晕的亮点。节点视图按节点宽高在边框中线上铺四条轨道并设置方向、边长和尾迹长度（边长的 40%），样式只做平移动画；轨道两端止于角点并裁剪流星，形成“从角飞出、没入下一个角”，宽度方向允许流星与光晕溢出边框（运行中节点以 overflow: clip 放宽 16px 绘制范围，不支持 overflow-clip-margin 的浏览器退化为在节点边界内裁剪）。每轮约 80% 时间运动、其余为间隔。流星层不接收指针，不写入文档或历史。
- 与连线流光共用暂停条件：视图隐藏或页面不可见时暂停，系统开启 prefers-reduced-motion 时隐藏流星，只保留静态强调色边框。

## 用户路径与交互边界

管理台增加独立“工作流”入口，原有 JSON／ENV 页面保持不变。运行和交互遵循以下边界：

1. 在节点库添加唯一的开始节点，将“开始”输出接入对比节点“启动”控制输入；两个文本节点分别连接 A/B 数据输入，再将差异输出连到结果节点。JSON/ENV 样例一次插入五节点四边：开始、对比、结果同排，两个文本位于开始节点下方；先建立 A/B 与结果三条数据边，最后建立开始到对比的控制边。**载入样例、导入、切换或恢复草稿都不自动运行。**开始节点只显示本流程专用凭据表单（GitHub Token、AI 地址/密钥/模型/思考开关、飞书 App ID/Secret，密钥为密码框）；某组凭据填写后，本流程的远程节点优先使用该组，留空的组仍使用 Token 配置。凭据与节点双向联动高亮：选中 GitHub、AI、飞书节点时，开始节点中对应凭据组的输入框以琥珀色描边和光晕高亮、标签同色；聚焦开始节点的某个凭据字段时，使用该组凭据的节点以琥珀色外框和光晕高亮，离开字段后取消。对应关系来自远程节点定义的 `credentialGroup` 与凭据字段的 `group`。名称与执行状态由通用节点壳呈现。
2. 连线只允许已注册、数据类型相容（相同，或 json 与其语义子类型之间）且 `kind` 相符的输出点到输入点；禁止自连、成环、同一来源重复接入，以及未声明多来源的输入接入多个来源（多来源输入在端口说明中标注“多来源”，例如 JSON 合并的“输入”）。无效操作必须显示原因且不能修改文档及撤销历史。未知节点/版本的原有连线可在导入时保留，不能从界面新增与未知实现相关的连接。
3. 显式点击“运行”才从唯一开始节点启动；开始节点必须有出边，入口成功后才调度沿边可达的处理／展示节点和它们所需的被动数据节点。范围外节点显示跳过、不发请求；已触发分支失败只阻断其下游，范围外任务也不会因为数据依赖被暗中执行。除开始节点外，节点头部的“▶ 从此节点运行”复用上游已成功的结果，只重跑该节点及其下游；上游任务没有可复用结果时提示先运行整图。“停止”取消等待和后续调度。每份流程的运行状态独立，切换流程不终止其他流程，所有流程共享执行并发额度。详情见 [执行与存储](./执行与存储.md)。
4. 正在运行的流程禁止修改文本/配置、名称、节点和连线，也不能复制、删除、撤销或重做；允许平移/缩放/保存视口、切换到其他流程和新建流程。运行锁在 `Workspace` 核心强制执行，不以按钮是否禁用为唯一保障。
5. 页面提供新建、名称编辑、JSON 导入导出、项目目录切换和 Ctrl／Command+S 文件保存；核心仍保留复制、删除、多流程选择和独立撤销/重做能力，顶部不再显示对应控件。新建空流程仍为空；旧 v1 无开始节点的草稿可恢复和编辑，不静默加节点或控制边，但运行会提示添加开始节点；入口存在却无出边时提示连接处理节点的“启动”输入。`parseDocument` 统一保证一份流程至多一个已注册的 entry：第二个入口的导入、添加、复制所选或子图插入均原子拒绝，不留下局部变更；整份流程复制保留唯一入口。导入验证成功后**作为新流程**加入，不覆盖同标识原件；复制不复制结果或历史；删除最后一份流程时自动留一份空流程。导出仅含文档定义和用户输入，不含运行输出，也不含开始节点凭据（导出时清空，导入文件中的凭据不采用；复制流程保留）。
6. 画布支持拖动/点击节点库、框选和 Ctrl／Command 多选、端口拖线、节点尺寸调整、视口缩放与适应画布；连线直接在画布上点击或通过 Tab 聚焦选择，不显示辅助连线面板。画布聚焦时 Ctrl／Command+Z 撤销，Ctrl／Command+Shift+Z 或 Ctrl／Command+Y 重做，Ctrl／Command+D 复制所选，Delete 删除；输入框内保留原生文字编辑快捷键。Ctrl+左键拖动空白处平移，普通左键拖动空白处框选，Ctrl／Command 点击节点左上角的类型标签多选，点击名称、参数、状态、端口说明、结果或其他节点区域及聚焦输入框均不改变选择；类型标签始终可见，Tab 聚焦后用 Enter／Space 选中，配合 Ctrl／Command 可切换多选。节点只能按住左上角类型标签拖动（仅该处显示移动光标，无按钮悬停/点击效果）；节点内其余区域不触发拖动或框选，名称、端口说明、错误信息、JSON 解析等预览和文本结果都可用鼠标原生选中并复制。节点拖动、空白框选、Ctrl／Command+A 全选与新增/复制后的程序化选择仍保留；也可按住右键或中键拖动画布。画布不允许滚轮、触控板滚动或方向键平移，不提供原生滚动条；Ctrl／Command+滚轮以鼠标所在位置为中心放大缩小，不再设 20% 的缩小下限，最大为 200%；纯横向滚轮不缩放，样例载入后仍自动适应画布。节点内部文本和结果仍可滚动，滚到边缘不带动画布或外层页面。Ctrl 平移只接管空白，不劫持文本框、节点或目录搜索；运行中仍可平移，鼠标释放或窗口失焦后退出平移状态，不产生节点编辑历史。单次样例载入和多节点拖动均只占一条撤销记录。

视图订阅 `Workspace.subscribe((documentId, event) => …)`，按 `workspace / structure / content / layout / viewport / runtime` 事件局部刷新，不能用画布图库的内部 JSON 替代业务文档。节点内容和结构变化只让变化节点及其下游的旧结果失效，其他结果保留并将流程标为“结果部分过期”；布局变化和视口变化保留结果；视口不进撤销历史。位置/尺寸在交互结束后提交，连续文本编辑可合并撤销记录。文本输入采用 200ms 防抖；失焦、运行、工作区命令和页面离开前强制提交，避免运行使用旧输入。数据展示须用安全文本 API（例如 `textContent`、表单 `value`），不得将导入内容作为 HTML 或脚本执行。

## 恢复、范围和隐私提醒

文档结构、配置、文本原文及视口自动保存在当前浏览器 `localStorage`；刷新后可恢复文档，**不会恢复运行状态或结果，也不会发起比较请求或自动重跑**。关闭页面会丢失内存中的结果；重新查看结果需手动运行。JSON/ENV 输入可能含密钥等敏感值，本地草稿和导出的 JSON 均**明文原样保存，不加密、不自动脱敏**；请勿在共享浏览器输入秘密，分享导出文件前先检查内容。手动运行会将完整 A/B 原文送到本服务的既有对比接口，不是离线比较；后端不持久化执行输入与结果；用户显式保存到固定项目目录的工作流定义是单独获准的文件备份例外。

本期**不支持**脱离上游结果的孤立单节点运行（“从此节点运行”必须复用上游已成功结果）、文件/图片节点、条件或循环、子流程、用户在线脚本、自定义远程接口、后台任务或通用服务端持久化（仅明确允许的 `public/workflow` 工作流 JSON 备份例外）。扩展新节点由开发者注册受控实现，不等于让用户在页面中输入可执行代码；扩展协议见 [节点扩展](./节点扩展.md)。
