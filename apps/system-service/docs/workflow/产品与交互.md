# 产品与交互

## 定位与本期范围

用户已确认将工作流作为**通用、可扩展的有类型数据流画布**，而非只为对比功能定制的连线页面。首批内置节点由 `public/js/workflow-nodes.js` 注册：

| 节点 | 输入 | 输出 | 用途 |
| --- | --- | --- | --- |
| 开始 `start@1` | 无 | `trigger: trigger`（control，值为 `true`） | 唯一显式执行入口 |
| 文本 `text@1` | 无；节点配置中的原文 | `text: text`（data） | 被动提供本次执行使用的文本 |
| JSON 对比 `json-compare@1` | 可选 `trigger: trigger`（control）；必需 `a: text`、`b: text`（data） | `diff: diff`（data） | 将两侧原文送到已有 JSON 对比接口 |
| ENV 对比 `env-compare@1` | 可选 `trigger: trigger`（control）；必需 `a: text`、`b: text`（data） | `diff: diff`（data） | 将两侧原文送到已有 ENV 对比接口 |
| 对比结果 `diff-result@1` | 必需 `diff: diff`（data） | `diff: diff`（data） | 在节点内展示结构化结果，并原样向下游转发 |

典型流向是开始节点的“开始”控制输出连接对比节点的“启动”输入，两个文本节点分别连接对比节点的 A/B 数据输入，再将 `diff` 数据输出连接结果节点；结果节点依赖数据边继续激活，不需要单独的控制输入。开始节点可以触发多个处理分支，但每份流程最多一个开始节点，每个输入端口至多一个来源。端口须同时匹配 `dataType` 和 `kind`，控制信号不混入对比的 A/B 业务数据。结果节点约定展示 A/B 对照、高亮分段、统计和可折叠差异树，不另提供 A/B 文本输出。A/B 文本窗格在各自滚动条旁提供固定差异概览轨道：新增绿色、删除红色、修改青色，按各侧全文的相对行位置分布，连续同类差异合并。轨道不随正文滚动、不阻挡鼠标，也不提供点击跳转；尺寸变化后保持相对位置。更新、失败或清空结果时清除旧标记，JSON／ENV 共用相同的 diff.segments 渲染规则。`diff` 结果形状与后端协议见 [内容对比 API](../content-compare/API.md)；工作流对比适配只调用已有 `POST /api/content-compare/json` 与 `/api/content-compare/env`，**没有新增 API**。

## 外观与节点库

工作流采用根 `DESIGN.md` 中的暗黑局部例外，包含画布、工具栏、节点、差异结果和当前路由的管理台壳层。离开 `#workflow` 后恢复其他页面的浅色风格，不保存全站主题状态。图元与控件统一使用 `--wf-*` 令牌，状态文字和差异标签仍保留。

节点库按注册定义的 category 展示为可折叠文件夹；`/` 分隔的分类支持多级目录。搜索支持名称、类型、分类和端口信息，不区分大小写，多个关键词按“全部匹配”过滤；只搜索节点元信息，不搜索工作流输入原文。搜索自动展开匹配路径，清除搜索恢复此前的折叠状态，提供匹配数量、无结果提示、清除按钮和 Escape 清除。查询与折叠仅保留在当前视图内，切换流程仍保留，刷新后重置，不进入文档或撤销历史，也不发请求。运行时可以继续搜索和折叠，但节点添加/拖入保持锁定。

## 连线选择与流光

连线通过节点端口拖动创建，不再提供键盘连线表单或连线列表。线条不显示文字标签或箭头；源端口和目标端口仍决定数据方向，业务文档及执行规则不变。节点内的端口名称继续保留。

- 点击线条直接选中，Ctrl／Command 点击可多选；选中的线原地暂停流光并增强描边和光晕，未选中的线继续流动，取消选中后从暂停处恢复。可用 Delete 或工具栏“删除所选”移除，并支持撤销重做。运行时仍可选中查看和暂停该线的视觉效果，但不能删除。
- 源端和目标端都连接端口圆心，使用中心 anchor 与 anchor connectionPoint，不按圆的外边缘裁剪，也不依赖像素偏移补偿；缩放、平移及节点尺寸变化后仍按实际圆心计算。
- 透明宽命中路径与光效分离，缩放后仍保持可点击宽度；光晕、底线和光点不接收指针，不遮挡节点输入、端口拖线或 Ctrl 空白平移。Tab 聚焦连线后可选中，Enter／Space 操作及 Delete 删除仍可用，可访问名称与选择状态不作为可见标签展示。
- 少量光点通过浏览器原生 CSS 路径动画（offset-path / offset-distance）沿实际连接曲线循环，随节点移动和尺寸调整同步。每条线有独立播放状态，不使用逐帧 JavaScript，不将光效写入工作流文档或历史；持续流动仅表示视觉数据方向，不表示后端正在执行，也不会自动发起请求。
- 工作流切换到隐藏状态、页面不可见或系统开启 prefers-reduced-motion 时，隐藏流动光点并暂停对应路径动画；恢复可见且允许动效后，只有未选中的线继续流动。静态连线和选中反馈始终保留，销毁视图时解除监听和观察器。

## 用户路径与交互边界

管理台增加独立“工作流”入口，原有 JSON／ENV 页面保持不变。运行和交互遵循以下边界：

1. 在节点库添加唯一的开始节点，将“开始”输出接入对比节点“启动”控制输入；两个文本节点分别连接 A/B 数据输入，再将差异输出连到结果节点。JSON/ENV 样例一次插入五节点四边：开始、对比、结果同排，两个文本位于开始节点下方；先建立 A/B 与结果三条数据边，最后建立开始到对比的控制边。**载入样例、导入、切换或恢复草稿都不自动运行。**开始节点显示静态使用说明，名称与执行状态由通用节点壳呈现。
2. 连线只允许已注册且 `dataType` 和 `kind` 同时相符的输出点到输入点；禁止自连、成环和一个输入多来源。无效操作必须显示原因且不能修改文档及撤销历史。未知节点/版本的原有连线可在导入时保留，不能从界面新增与未知实现相关的连接。
3. 显式点击“运行”才从唯一开始节点启动；开始节点必须有出边，入口成功后才调度沿边可达的处理／展示节点和它们所需的被动数据节点。范围外节点显示跳过、不发请求；已触发分支失败只阻断其下游，范围外任务也不会因为数据依赖被暗中执行。“停止”取消等待和后续调度。每份流程的运行状态独立，切换流程不终止其他流程，所有流程共享执行并发额度。详情见 [执行与存储](./执行与存储.md)。
4. 正在运行的流程禁止修改文本/配置、名称、节点和连线，也不能复制、删除、撤销或重做；允许平移/缩放/保存视口、切换到其他流程和新建流程。运行锁在 `Workspace` 核心强制执行，不以按钮是否禁用为唯一保障。
5. 流程支持新建、重命名、复制、切换、删除、JSON 导入导出及每份流程独立撤销/重做。新建空流程仍为空；旧 v1 无开始节点的草稿可恢复和编辑，不静默加节点或控制边，但运行会提示添加开始节点；入口存在却无出边时提示连接处理节点的“启动”输入。`parseDocument` 统一保证一份流程至多一个已注册的 entry：第二个入口的导入、添加、复制所选或子图插入均原子拒绝，不留下局部变更；整份流程复制保留唯一入口。导入验证成功后**作为新流程**加入，不覆盖同标识原件；复制不复制结果或历史；删除最后一份流程时自动留一份空流程。导出仅含文档定义和用户输入，不含运行输出。
6. 画布支持拖动/点击节点库、框选和 Ctrl／Command 多选、端口拖线、节点尺寸调整、视口缩放与适应画布；连线直接在画布上点击或通过 Tab 聚焦选择，不显示辅助连线面板。画布聚焦时 Ctrl／Command+Z 撤销，Ctrl／Command+Shift+Z 或 Ctrl／Command+Y 重做，Ctrl／Command+D 复制所选，Delete 删除；输入框内保留原生文字编辑快捷键。Ctrl+左键拖动空白处平移，普通左键拖动空白处框选，Ctrl／Command 点击节点多选；也可按住右键或中键拖动画布。画布不允许滚轮、触控板滚动或方向键平移，不提供原生滚动条；Ctrl／Command+滚轮以鼠标所在位置为中心放大缩小，范围为 20%～200%；纯横向滚轮不缩放，工具栏缩放和适应画布仍可用。节点内部文本和结果仍可滚动，滚到边缘不带动画布或外层页面。Ctrl 平移只接管空白，不劫持文本框、节点或目录搜索；运行中仍可平移，鼠标释放或窗口失焦后退出平移状态，不产生节点编辑历史。单次样例载入和多节点拖动均只占一条撤销记录。

视图订阅 `Workspace.subscribe((documentId, event) => …)`，按 `workspace / structure / content / layout / viewport / runtime` 事件局部刷新，不能用画布图库的内部 JSON 替代业务文档。节点内容和结构变化使该流程旧结果失效，布局变化和视口变化保留结果；视口不进撤销历史。位置/尺寸在交互结束后提交，连续文本编辑可合并撤销记录。文本输入采用 200ms 防抖；失焦、运行、工作区命令和页面离开前强制提交，避免运行使用旧输入。数据展示须用安全文本 API（例如 `textContent`、表单 `value`），不得将导入内容作为 HTML 或脚本执行。

## 恢复、范围和隐私提醒

文档结构、配置、文本原文及视口自动保存在当前浏览器 `localStorage`；刷新后可恢复文档，**不会恢复运行状态或结果，也不会发起比较请求或自动重跑**。关闭页面会丢失内存中的结果；重新查看结果需手动运行。JSON/ENV 输入可能含密钥等敏感值，本地草稿和导出的 JSON 均**明文原样保存，不加密、不自动脱敏**；请勿在共享浏览器输入秘密，分享导出文件前先检查内容。手动运行会将完整 A/B 原文送到本服务的既有对比接口，不是离线比较；后端不持久化业务输入与结果。

本期**不支持**单节点运行、文件/图片节点、条件或循环、子流程、用户在线脚本、自定义远程接口、后台任务或服务端持久化。扩展新节点由开发者注册受控实现，不等于让用户在页面中输入可执行代码；扩展协议见 [节点扩展](./节点扩展.md)。
