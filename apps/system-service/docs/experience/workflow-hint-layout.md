# 画布状态提示不得参与拖拽布局

## 问题与触发条件

工作流改成纵向 flex 满屏布局后，将空提示设为 `display:none`，非空提示仍作为普通 flex 项占用高度。X6 连线校验会即时清空或更新提示，鼠标拖线过程中画布因此上下移动约 27 像素，既有客户端坐标落到错误端口，出现“输入已有来源”或无法建立连接。

## 定位与处理

记录拖线前、mousedown 后、mousemove 后的 stage.top：普通文档流提示从 182.5625 变为 155.375；改为不占文档流的绝对定位提示后，三次均为 155.375，连线由 3 条恢复为 4 条。提示设为画布区域内不拦截指针的浮层，工作流根元素保持相对定位，避免动态文案或无障碍隐藏控件影响视口几何。

## 回归

`src/__tests__/workflow-browser-check.js` 在真实端口拖拽前设置非空提示，移动时断言画布顶部变化小于 0.75px，然后验证正式连接创建。布局修改不能仅检查最终节点/线条位置，还要验证交互期间状态区变化不会挤动画布。
