# 保存快照应先捕获未失焦输入

## 触发条件

工作流名称和节点文本都存在未失焦编辑时，Ctrl+S 先 flush 节点。节点提交会同步通知工作区，工具栏刷新又把未聚焦的名称输入更新为旧模型值；保存随后读取名称，产生旧文件名和旧文档名称。

## 处理

在触发任何节点提交前，先捕获当前文档 ID 与名称输入值；再提交节点、校验/提交已捕获名称，最后提交视口并生成导出快照。队列仅捕获 id/name/text，文件版本在队列执行时读取，成功后先更新版本再处理下一项。不要在名称丢失后尝试通过新 UI 值补回。

## 回归

`src/__tests__/workflow-save-browser-check.js` 同时设置节点文本与未失焦名称，从节点输入焦点触发 Ctrl+S，断言 POST 的 filename、文档 name、节点文本、视口都是最新值。首次验证曾出现旧文件名，修复后通过；保存失败不发半旧请求，来源冲突不自动覆盖。
