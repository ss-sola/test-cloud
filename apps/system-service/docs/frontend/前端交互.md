# 前端管理台交互

## 桌面端布局

- 左侧固定主导航，右侧为可滚动主体内容区。
- 当前只保留“工作台总览”入口，活动状态通过 `aria-current="page"` 标识。

## 页面切换

页面使用 `#overview` 作为唯一合法 hash。页面加载或 hash 变化时，脚本会：

- 将未知 hash 规范化为 `#overview`。
- 显示工作台总览主体。
- 更新面包屑、页面标题和活动导航状态。

## 移动端

屏幕宽度小于 768px 时：

- 主导航变为从左侧滑出的抽屉。
- 顶部显示导航开关按钮，按钮提供准确的 `aria-label` 和 `aria-expanded`。
- 点击遮罩层或按 `Escape` 关闭抽屉。
- 页面保持 320px 最小宽度，并避免横向溢出。

## 可访问性与动效

- 页面提供跳过导航链接、语义化导航区域、标题层级和键盘焦点样式。
- 图标使用内联 SVG 并标记为装饰内容，不依赖 emoji 传达信息。
- `prefers-reduced-motion: reduce` 下关闭主要过渡动画。
- 新增可交互控件时，必须同步补充键盘操作、可见焦点和必要的 ARIA 状态。
