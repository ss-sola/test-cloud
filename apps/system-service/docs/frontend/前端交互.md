# 前端管理台交互

## 导航与页面切换

- 左侧导航包含工作台总览、粒子动画、JSON 对比、ENV 对比、工作流、周报生成、BullMQ 面板、配置版本预览、Token 配置和论文查重十个入口。
- 页面使用 `#overview`、`#particle`、`#json-compare`、`#env-compare`、`#workflow`、`#weekly-report`、`#bullmq`、`#config-file-preview`、`#token-config` 和 `#plagiarism` 作为合法 hash。
- 页面 section 以 fragment 形式位于 `public/html/`，入口页只保留管理台壳层；`app.js` 加载 fragment 后再挂载对应控制器。
- 页面加载和 hash 变化时，脚本同步当前主体、导航活动态、`aria-current`、面包屑和 `document.title`；未知 hash 回退到总览。
- 菜单切换不触发整页重载，并在移动端自动关闭抽屉。
- 桌面侧栏可折叠；小于 768px 时侧栏转为抽屉，点击遮罩、菜单项或按 `Escape` 可关闭，关闭后焦点回到触发控件。

## 粒子动画

1. 在上传区选择或拖入一张或两张 PNG、JPEG、WEBP、GIF 图片。
2. 单文件超过 15 MB 或不是图片时显示错误，不进入处理流程。
3. 图片以本地对象 URL 读取，不上传服务器；素材 A 和 B 可分别替换或移除。
4. 图片边缘在 Canvas 中转换为粒子，显示当前粒子数；素材 A 就绪后可调整 1,000～10,000 的粒子密度。
5. 选择弹性、波浪或旋转至目标效果；同时存在 A/B 时，点击“切换至素材”按钮或直接点击画布可切换形态。
6. 画布指针附近的粒子会产生轻微排斥和点击爆发反馈；画布获得焦点后按 Enter 或空格也可触发切换。
7. 浏览器标签页不可见时暂停绘制，系统开启减少动画时自动使用低运动路径。
8. 图片无法解码、Canvas 不支持像素读取或没有清晰边缘时显示可读错误。

## JSON 对比

- A/B 两侧编辑器接收 JSON 原文。点击“对比 JSON”才会向本服务 `POST /api/content-compare/json` 提交 `{ left, right }`；原文不发送到第三方，但不再是离线工具。
- 后端按侧解析，空文本或无效 JSON 显示对应侧的安全错误信息；失败清除旧结果但保留原文。
- 成功后用服务端规范化文本回填两侧，文本与高亮分段严格一致。默认两空格缩进；缩进后超过 500000 字符时自动改为紧凑格式，紧凑格式仍超限则返回 413 并保留原输入。对象键和普通数组会规范化；对象数组通过唯一的 `id` 或 `*Id` 字段按身份匹配，身份值的类型也参与匹配。
- 服务端返回新增、删除、修改统计和可展开/收起的差异树（路径、A/B 显示值），编辑器按返回分段高亮并显示 marker，A/B 滚动同步；数字键的文本按分段拼接，前端不重算差异。
- JSON 草稿继续使用 `localStorage` 的 `nestcloud:compare:json:v1`；刷新后只恢复文本，不自动上传或比较。
- 两侧输入框上方的“对比 JSON”触发请求；“对调 A / B”先交换、保存，再立即请求比较。普通编辑立即清除旧结果、取消请求，仅更新本地草稿，不上传。

## ENV 对比

- A/B 两侧接收 `.env` 原文。点击“对比 ENV”或对调后向本服务 `POST /api/content-compare/env` 提交 `{ left, right }`；编辑与草稿恢复不上传。
- 后端支持 BOM、CRLF/CR/LF、空行、注释、`export KEY=value`、单/双引号、指定转义、行尾注释和空值；值保持字符串，不执行变量展开或命令。非法键、缺少等号、重复键、未闭合引号和尾随内容按侧显示安全错误，适用时带行号及重复键的先前行号。
- 保留 JSON 对象形式的兼容输入；比较成功后 ENV 编辑器始终保留原文（注释、换行和引号不变），JSON 对象兼容原文不标色。统计、树、滚动同步和高亮交互与 JSON 视图共用。
- ENV 草稿仍使用 `localStorage` 的 `nestcloud:compare:env:v1`；无效内容也保留原文，刷新后不自动比较。

比较请求处理中显示忙碌状态（`aria-busy`），重复比较、编辑、对调或失败后的迟到响应不能覆盖当前文本、结果或错误。前端 30 秒超时；网络错误、请求超限或其他 HTTP 失败保留原文并提示可重试，不在浏览器执行本地对比。详见 [接口协议](../content-compare/API.md)与[资源/隐私边界](../content-compare/实现与边界.md)。

## Token 配置

- “Token 配置”页面提供 GitHub Token、飞书 App ID/Secret 与周报/工作流 AI 配置。浏览器凭据存储键 `nestcloud:release-tokens:v1` 为兼容保留；历史数据里的 Jenkins 字段不在页面展示，下次显式保存不再写入。AI 配置保存在嵌套的 `ai.baseUrl`、`ai.apiKey`、`ai.model` 与 `ai.enableThinking` 中。
- AI Base URL 填写 OpenAI-compatible 服务的基础地址，不要附加 `/chat/completions`；API Key 使用 password 输入框，Model 填服务支持的模型名。“启用 AI 思考”默认未勾选；localStorage 旧值缺失或不为严格布尔 `true` 时均按 `false` 恢复，不将字符串 `"true"` 或 `null` 视为开启。保存及清空时保持这一默认关闭规则。周报与工作流每次执行都将当前布尔值显式传入 `runtime.ai.enableThinking`，服务端缺省亦按 `false` 处理。
- AI 三项去除首尾空白后必须全部填写，周报请求始终将完整配置作为 `runtime.ai` 发送。Token 页允许保存全部留空或不完整的草稿，但会提示无法生成周报；周报表单在创建任务前拦截这些配置，不发送创建请求，也不切换到本地摘要。
- 页面恢复时兼容历史存储中的 GitHub/飞书/AI 数据；清空凭据会移除已保存的凭据和 AI 配置，并继续派发 `nestcloud:tokens-updated` 事件。
- localStorage 不是加密存储。AI API Key 与其他凭据一样只能在受控浏览器和 HTTPS 管理台中使用，离开环境前应清空并定期轮换。

## 周报生成

- 进入“周报生成”后选择“上周”或“本周”，分别对应源项目的 `week:last` 和 `week:this`。
- “同步到飞书文档”默认不勾选；该选项仅对“上周”可用，选择“本周”时置灰。勾选后请求会在异步 Job 中传递 `publish.enabled: true` 和飞书配置，未勾选或选择本周时显式传递 `publish.enabled: false` 且不发送 App Secret。
- 勾选同步后可填写单个 Wiki 地址和 B 列姓名；App ID、App Secret 只读展示，从 Token 配置页读取。Wiki 地址必须包含 `?sheet=...` 查询参数，服务端固定使用 `A1:B200` 查找，不显示月份、查找范围或多目标控件；API 请求超时和临时错误重试次数由服务端控制。
- 项目配置、同步开关和飞书同步配置修改后保存到 `localStorage` 的 `nestcloud:weekly-report:v1`，页面首次挂载优先恢复有效草稿；不迁移旧 `monthlyTargets` 结构。
- App ID/App Secret 只从当前请求的页面配置提交，不从服务端环境变量或旧配置回退。GitHub Token 从 Token 配置页面读取并作为 `runtime.githubToken` 提交；tenant token 不进入页面。
- 点击生成后先通过 `POST /api/weekly-commit-reports/jobs` 创建任务，再轮询 `GET /api/weekly-commit-reports/jobs/status?jobId=...`；进度条直接显示后端返回的阶段和百分比，不再使用本地循环计时器。
- 结果区域展示周期、提交数量、摘要模式和 Markdown 内容；复制与下载均在浏览器中完成。历史 `degraded=true` 优先标为“历史本地结果”，否则 `commitCount=0` 标为“无可用提交（未调用 AI）”，有可用提交时标为“AI 摘要”。新生成成功结果的兼容字段 `degraded` 固定为 `false`。
- AI 配置缺失、请求失败、输出不符合要求或 prompt 超限时直接失败，不使用本地摘要；页面显示可读错误并清空旧 Markdown、隐藏复制/下载、清除旧项目异常。即使没有可用提交也需完整配置，但实际不调用 AI，不以空提交报告证明 AI 连通。
- 单个项目请求失败时，周报仍显示其他成功项目的 Markdown；结果区通过 `#weekly-report-project-errors` 展示失败项目、状态码和异常信息，复制/下载的 Markdown 也保留“项目异常”区块。

## 论文查重

- 进入“论文查重”后分别粘贴答案 A 和答案 B，输入 `0～1` 的高亮相似阈值以及非负整数编辑距离；每侧最多 10000 个字符。
- 点击开始查重后调用 `POST /api/plagiarism/compare`，处理中显示状态；请求失败时清除旧结果并以 `role="alert"` 显示错误。
- 页面会把答案 A、答案 B、阈值和编辑距离缓存到 `localStorage` 的 `nestcloud:plagiarism:v1`，刷新后恢复；查重请求仍显式提交本次完整参数，服务端不依赖之前请求。
- 结果区展示综合相似度、A 重复率、B 重复率、A 侧重复量和重复片段数；中文重复量按字统计，英文按完整单词统计，混合文本按中文字符/英文单词/其他字符单位统计；同一 A 片段在 B 中出现多次时，B 侧分别高亮每个位置，A 侧保留一个覆盖区间；底层高亮层只标记 A 方向通过阈值的重复片段，上层 readonly 原文 textarea 保留原始标点、空格和换行，并与高亮层同步滚动。
- 鼠标悬浮或键盘聚焦高亮片段时显示局部相似度、规范化长度和两侧原文位置；步骤卡片展示文本标准化、分句/分块、3-gram、块候选、Jaccard、SimHash、连续扩展、阈值筛选和最终区间的每一步数据。
- 清洗和计算在单次请求内完成；论文文本不写入 localStorage、sessionStorage、URL、Cookie 或服务端持久化存储。该结果只用于文本重合辅助判断，不能识别所有语义改写或替代正式学术检测。

## 工作流

- 新增 `#workflow`，保留独立 JSON／ENV 对比页面。工作流按局部设计例外采用暗黑风格，离开该路由恢复其他页面的浅色。节点库为分类文件夹，包含“流程控制/开始”，支持多级分类、搜索过滤、清除后折叠恢复和无结果提示。将唯一开始节点的“开始”（control/trigger）输出连接对比节点可选的“启动”控制输入，再把两个被动文本节点连到 A/B 数据端口，`diff` 数据输出连到结果节点；结果节点在画布中完整展示高亮、统计和可折叠差异树，并输出结构化差异数据。A/B 文本各有固定在滚动条旁的差异位置轨道，以绿色/红色/青色表示新增/删除/修改；按各侧全文行号定位，正文滚动不带动标记，不覆盖原生滚动条，也不提供点击跳转。开始节点只展示静态说明，名称和状态由通用节点壳展示。JSON/ENV 样例五节点四边：开始、对比、结果同排，两个文本位于开始节点下方；前三条为 A/B 与 diff 数据边，最后是控制边，不自动运行。
- 仅点击“运行”才启动：必须恰有一个有出边的开始节点，入口成功后执行从它沿控制／数据边可达的任务和按需引用的被动数据，不沿被动数据的其他出边扩张；范围外任务跳过不发请求。控制信号不混入 A/B 原文，业务请求仍用现有 `{left,right}` 接口；已触发的仅控制输入任务失败也计入流程终态。旧 v1 无入口草稿可恢复编辑，不静默改图，需补开始节点并连接对比“启动”后运行；导入或复制所选产生第二个入口会原子拒绝，整份流程复制仍可。未知版本始终阻止整图运行。编辑、导入和恢复不上传。运行锁定该流程的内容、配置和连接，允许视口操作与切换流程；失败只阻断相关下游。
- 通用原子能力提供日期/JSON 输入、解析、模板、GitHub 抓取、AI 文本、文本/Markdown 结果及独立飞书查找/写入。空画布可载入周报组合样例，六节点六边、一次撤销、不自动执行或发布；填写仓库/人员并完成 Token 配置后才运行。通用表单有防抖/失焦/运行前 flush、错误草稿提示和运行锁；文本结果可切换原文/安全 Markdown、复制下载完整内容。飞书写入每次确认实际目标和矩阵，不保存确认；AI 内容外发与取消后不可撤销写入的限制见 [原子能力说明](../workflow-capabilities/README.md)。
- 多流程分别保存版本化定义、输入和视口到当前浏览器，结果与运行状态不落盘；刷新或关闭后不恢复执行。保存和导出可能包含敏感输入，需在受控浏览器使用。
- 画布仅通过 Ctrl+左键拖动空白处或按住右键/中键拖动来平移；禁止滚轮、触控板滚动和方向键平移，Ctrl／Command+滚轮以鼠标位置为中心缩放（20%～200%），也可使用工具栏调整比例或适应画布。节点内部文本与结果仍可滚动，滚到边缘不带动画布或外层页面。普通左键空白拖动框选；只有点击节点左上角的类型标签才改变节点选择，Ctrl／Command 点击该标签切换多选，Tab 聚焦后可用 Enter／Space 激活。点击或聚焦名称、参数和结果等其他区域不选中节点，窄节点也保留类型标签。节点添加、拖动连线、复制/删除、撤销重做、缩放、适应画布和结果尺寸调整等交互见 [产品与交互](../workflow/产品与交互.md)。

## BullMQ 面板

- 进入“BullMQ 面板”后，管理台加载服务端 `/ops/queues/` 的 Bull Board 页面；也可点击“新窗口打开”。
- 面板只展示固定的 `weekly-report` 队列，使用 `bull` prefix 和只读 adapter；队列由服务端 Worker 实际消费，任务状态会在页面中刷新。
- 面板路由只允许 GET，请求写操作返回 405；Redis stats 不向页面开放。生产环境默认要求登录会话和固定的 `ops:queue:read` 权限码。
- 周报任务使用 BullMQ Worker 执行，创建后的 `queued`、`running`、`succeeded`、`failed` 状态会映射回现有周报轮询接口。

## 可访问性与动效

- 页面提供跳过导航链接、语义化导航、标题层级、可见键盘焦点和 `aria-current`。
- 文件输入、滑块、选择框和按钮均有可读标签；处理状态使用 `aria-live`，错误使用 `role="alert"`。
- 差异高亮层和 marker 为 `aria-hidden`，差异树使用 `tree/treeitem`、层级和展开状态属性。
- 用户输入只作为文本节点或 textarea value 写入；不依赖颜色或图标单独表达结果。
- `prefers-reduced-motion: reduce` 下禁用主要 CSS 过渡并降低 Canvas 运动。
