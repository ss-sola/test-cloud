# 前端管理台交互

## 导航与页面切换

- 左侧导航包含工作台总览、粒子动画、JSON 对比、ENV 对比、周报生成、BullMQ 面板和配置版本预览七个真实入口。
- 页面使用 `#overview`、`#particle`、`#json-compare`、`#env-compare`、`#weekly-report`、`#bullmq` 和 `#config-file-preview` 作为合法 hash。
- 页面 section 以 fragment 形式位于 `public/html/`，入口页只保留管理台壳层；`app.js` 加载 fragment 后再挂载对应控制器。
- 页面加载和 hash 变化时，脚本同步当前主体、导航活动态、`aria-current`、面包屑和 `document.title`；未知 hash 回退到总览。
- 菜单切换不触发整页重载，并在移动端自动关闭抽屉。
- 桌面侧栏可折叠；小于 768px 时侧栏转为抽屉，点击遮罩、菜单项或按 `Escape` 可关闭，关闭后焦点回到触发控件。

## 粒子动画

1. 在上传区选择或拖入一张或两张 PNG、JPEG、WEBP、GIF 图片。
2. 单文件超过 15 MB 或不是图片时显示错误，不进入处理流程。
3. 图片以本地对象 URL 读取，不上传服务器；素材 A 和 B 可分别替换或移除。
4. 图片边缘在 Canvas 中转换为粒子，显示当前粒子数；素材 A 就绪后可调整 1,000～10,000 的粒子密度。
5. 选择弹性、波浪或旋转至目标效果；同时存在 A/B 时，点击“切换至素材”按钮或直接点击画布可切换形态。
6. 画布指针附近的粒子会产生轻微排斥和点击爆发反馈；画布获得焦点后按 Enter 或空格也可触发切换。
7. 浏览器标签页不可见时暂停绘制，系统开启减少动画时自动使用低运动路径。
8. 图片无法解码、Canvas 不支持像素读取或没有清晰边缘时显示可读错误。

## JSON 对比

- A/B 两侧编辑器分别接收 JSON 文本，点击“对比 JSON”后执行解析。
- 空文本或无效 JSON 按侧显示错误，原文保留，已有结果清除。
- 成功后对象键和数组被规范化，两侧回填为两空格缩进 JSON。
- 差异结果显示新增、删除、修改数量，并以路径、A 值、B 值组成可展开/收起的差异树。
- 含唯一 `id` 或 `*Id` 字段的对象数组按身份匹配，普通数组按规范化顺序比较。
- 编辑器背景显示差异高亮和右侧 marker；A/B 编辑器滚动位置保持同步。
- JSON 两侧文本保存到 `localStorage` 的 `nestcloud:compare:json:v1`，刷新后恢复文本但不自动比较。
- 对比按钮位于两侧输入框上方左侧；右侧“对调 A / B”按钮交换两侧文本，并立即重新执行比较。

## ENV 对比

- A/B 两侧接收 `.env` 文本，点击“对比 ENV”后按字符串键值解析。
- 支持空行、注释、`export KEY=value`、单/双引号、指定转义、行尾注释和空值。
- 值不做数字、布尔或变量展开；非法键、缺少等号、重复键、未闭合引号和尾随内容显示行号错误。
- 如果内容以 `{` 开始，先兼容规范化 JSON 对象；比较成功后仍保留原始 ENV 文本，并在结果树中显示差异。
- ENV 与 JSON 共用差异树、统计、滚动同步和高亮交互。
- ENV 两侧文本保存到 `localStorage` 的 `nestcloud:compare:env:v1`，无效内容也保留原文，刷新后不自动比较。

## 周报生成

- 进入“周报生成”后选择“上周”或“本周”，分别对应源项目的 `week:last` 和 `week:this`。
- “同步到飞书文档”默认不勾选；该选项仅对“上周”可用，选择“本周”时置灰。勾选后请求会在异步 Job 中传递 `publish.enabled: true` 和完整的 `publish.settings`，未勾选或选择本周时显式传递 `publish.enabled: false` 且不发送 App Secret。
- 勾选同步后可填写 App ID、App Secret、飞书 API 请求超时、临时错误重试次数，以及月度目标的月份、Wiki 地址、Sheet ID、A:B 查找范围和 B 列姓名。Wiki 地址支持 `/wiki/<token>` 和 `/sheets/<spreadsheetToken>?sheet=<sheetId>` 两种格式；粘贴带 `?sheet=...` 的地址时，Sheet ID 为空会自动填充。
- 项目配置独立放在页面下方的卡片中，支持添加和删除，始终保留 1～10 个项目；仓库地址变化会同步更新卡片标题。
- 项目配置、同步开关和飞书同步配置修改后保存到 `localStorage` 的 `nestcloud:weekly-report:v1`，页面首次挂载优先恢复有效草稿；旧草稿缺少新字段时使用默认值。
- App Secret 按当前产品要求会持久化在浏览器 localStorage，只应在受信任的内部管理台和 HTTPS 环境使用；GitHub Token 和飞书 tenant token 不进入页面。
- 点击生成后先通过 `POST /api/weekly-commit-reports/jobs` 创建任务，再轮询 `GET /api/weekly-commit-reports/jobs/status?jobId=...`；进度条直接显示后端返回的阶段和百分比，不再使用本地循环计时器。
- 结果区域展示周期、提交数量、摘要模式和 Markdown 内容；复制与下载均在浏览器中完成。
- 摘要服务不可用或未配置时，服务端使用提交标题规则降级，并在结果状态中标记“本地”。Git、AI 超时或仓库错误显示可读错误信息。
- 单个项目请求失败时，周报仍显示其他成功项目的 Markdown；结果区通过 `#weekly-report-project-errors` 展示失败项目、状态码和异常信息，复制/下载的 Markdown 也保留“项目异常”区块。

## BullMQ 面板

- 进入“BullMQ 面板”后，管理台加载服务端 `/ops/queues/` 的 Bull Board 页面；也可点击“新窗口打开”。
- 面板只展示固定的 `weekly-report` 队列，使用 `bull` prefix 和只读 adapter；队列由服务端 Worker 实际消费，任务状态会在页面中刷新。
- 面板路由只允许 GET，请求写操作返回 405；Redis stats 不向页面开放。生产环境默认要求登录会话和固定的 `ops:queue:read` 权限码。
- 周报任务使用 BullMQ Worker 执行，创建后的 `queued`、`running`、`succeeded`、`failed` 状态会映射回现有周报轮询接口。

## 可访问性与动效

- 页面提供跳过导航链接、语义化导航、标题层级、可见键盘焦点和 `aria-current`。
- 文件输入、滑块、选择框和按钮均有可读标签；处理状态使用 `aria-live`，错误使用 `role="alert"`。
- 差异高亮层和 marker 为 `aria-hidden`，差异树使用 `tree/treeitem`、层级和展开状态属性。
- 用户输入只作为文本节点或 textarea value 写入；不依赖颜色或图标单独表达结果。
- `prefers-reduced-motion: reduce` 下禁用主要 CSS 过渡并降低 Canvas 运动。
