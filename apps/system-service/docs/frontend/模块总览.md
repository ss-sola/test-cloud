# 前端管理台模块总览

## 目标

`system-service` 为 NestCloud 提供统一的系统工作区，图片转粒子仍是无需后端接口的本地工具；JSON 与 ENV 对比使用本服务的即时计算接口。工具页面与工作台总览共用左侧导航、顶栏和响应式布局；周报配置由本次请求携带，配置版本预览从 GitHub Contents API 返回指定或自动解析的 tag 对应文件内容。论文查重通过 system-service 的无状态即时接口完成两段文本计算。

## 资源位置

- 源目录：`apps/system-service/public/`
- 页面入口：`/public/index.html`
- 样式：`/public/css/app.css`
- 页面控制器：`/public/js/app.js`（加载并挂载 `/public/js/content-compare.js` 的比较视图）
- 纯展示与 Canvas 脚本：`/public/js/`
- 页面 fragments：`/public/html/`
- 构建目录：`apps/system-service/dist/public/`
- 静态服务：`ServeStaticModule`，挂载路径为 `/public`

`nest-cli.json` 将源目录资源复制到构建目录，`dist/public/` 不作为源码维护。浏览器脚本使用 Node 可安全加载的自执行兼容封装，避免公共自动注册器扫描构建目录时访问 DOM。`app.js` 根据固定路由表加载 `public/html/*.html`，校验单一 section 根节点后挂入 `#view-host`；已加载视图只隐藏不卸载，以保留页面状态。BullMQ 面板由服务端以 `/ops/queues` 独立挂载，管理台通过 fragment iframe 嵌入。

## 页面入口（十个）

| Hash | 页面 | 说明 |
| --- | --- | --- |
| `#overview` | 工作台总览 | 系统管理台工作区首页 |
| `#particle` | 粒子动画 | 本地图片边缘粒子与 A/B 形态切换 |
| `#json-compare` | JSON 对比 | 原文提交本服务，返回结构树与高亮分段 |
| `#env-compare` | ENV 对比 | 原文提交本服务，保留 `.env` 原文展示 |
| `#workflow` | 工作流 | 唯一开始节点触发的类型化无环编排、手动运行可达任务及节点内完整差异结果；支持多流程浏览器草稿 |
| `#weekly-report` | 周报生成 | 选择上周或本周，按请求中的 GitHub 仓库和 runtime 配置生成 Markdown 汇总；可选发布到单个飞书 Sheet 工作日单元格 |
| `#bullmq` | BullMQ 面板 | 以内嵌 Bull Board 只读查看 `weekly-report` 队列的任务状态 |
| `#config-file-preview` | 配置版本预览 | 通过 GitHub Contents API 查看指定 tag 的配置文件 |
| `#token-config` | Token 配置 | 管理 GitHub、飞书 App ID/Secret 和周报 AI 摘要配置 |
| `#plagiarism` | 论文查重 | 比较两段答案，按阈值高亮重复片段并展示九步相似数据 |

空 hash、未知 hash 或非法 hash 会被规范化为 `#overview`。页面切换只改变当前视图，不整页刷新。

## 功能边界

- 图片仍在浏览器本地处理，不上传。JSON 与 ENV 只在点击比较或对调时分别向本服务 `POST /api/content-compare/json`、`POST /api/content-compare/env` 发送 `{ left, right }` 原文；恢复草稿、输入和页面挂载不发请求。后端仅即时处理，不持久化、不缓存、不外发输入或结果；协议与隐私边界见 [内容对比文档](../content-compare/README.md)。
- BullMQ 面板路径为 `/ops/queues`，固定展示 `weekly-report` 队列，使用 `bull` prefix 和只读 adapter；面板路由仅允许 GET 并隐藏 Redis stats，生产环境应启用登录会话和 `ops:queue:read` 权限。周报任务已经由 BullMQ Worker 执行并会显示在面板中。
- 周报菜单通过 `POST /api/weekly-commit-reports/jobs` 创建异步任务并轮询状态；单项目请求失败时跳过该项目并在 `projectErrors` 中显示异常，其他项目和 Markdown 结果继续生成。启用飞书发布后，仅针对 `last-week` 使用单个 Wiki 配置，固定在 `A1:B200` 按 A 列工作日日期范围和 B 列姓名定位行，然后只写该行 C-G 五个工作日单元格；内容相同跳过，发布失败仍保留报告。返回内容只在浏览器中展示、复制或下载，不写入用户指定的服务器路径。
- 周报必须提供完整 AI runtime 配置，缺失或空白配置在创建任务前被页面拦截，后端同样拒绝；AI 请求失败、输出非法或 prompt 超限时整次生成失败，不使用本地摘要。没有可用提交时不调用 AI，结果标为“无可用提交（未调用 AI）”；历史 `degraded=true` 结果标为“历史本地结果”。AI 配置由 Token 页面从当前浏览器 localStorage 读取，仅随本次请求进入服务端执行上下文，不进入静态资源、Job 状态或结果响应。
- 粒子动画只使用 Canvas、Image、ResizeObserver 和 Pointer Events；图片对象 URL 在替换、删除和页面销毁时释放。
- 解析、对象键排序、数组匹配和差异计算在后端纯类中完成；ENV 值保持字符串，不执行变量展开、shell 命令或多行脚本。
- JSON 比较成功后，从服务端分段拼接规范化文本回填两侧编辑器；ENV 比较保留原始输入（含 JSON 对象兼容输入，不标色）。
- 配置版本预览页面要求用户填写 repository、branch、filePath 和 Token；tag 可手动填写，留空时由服务端按 GitHub tags 返回顺序自动解析，fragment 由 `config-file-preview.js` 挂载。
- 论文查重页面提交两段各不超过 10000 字的文本、`[0, 1]` 相似阈值和非负整数编辑距离，服务端按文本标准化、分句/分块、块候选、连续匹配扩展、区间合并顺序执行；返回 A、B 两个方向的重复率，A 方向以 A 的重复统计单位/总单位展示，B 方向同理，通过阈值的 A 方向片段返回原文 UTF-16 区间，前端使用 ENV 对比式高亮叠层和原文 textarea，并通过悬浮/聚焦显示片段数据，九个步骤均在结果区展开。
- BullMQ 面板配置使用 `SessionRedisUrl` 读取 Redis，队列名 `weekly-report` 和 prefix `bull` 固定定义在周报常量中；Redis 地址不接受浏览器参数。
- 周报项目配置、JSON 与 ENV 编辑文本使用版本化 localStorage 草稿，缓存损坏时回退到页面默认值。

- 工作流定义及原文只保存在本机 `localStorage`，执行结果与状态仅在页面内存；刷新不自动运行。每份流程至多一个注册为 `entry` 的节点，运行时须恰好一个且至少有一条出边；旧 v1 无入口草稿可恢复编辑，手动添加开始节点并连接处理节点的控制启动端口后才能运行，未知节点版本仍阻止运行。节点端口数据类型与 `data/control` 种类须同时匹配；仅入口可达的任务（含由 data 边继续触发的结果节点）及它们需要的被动数据执行，不触发共享数据来源的其他分支。可选控制输入与原 A/B 业务输入分离，实际比较仍复用现有无状态接口；活动任务失败计入终态，范围外跳过节点不计入汇总。产品交互、扩展协议和执行预算分别见 [产品与交互](../workflow/产品与交互.md)、[节点扩展](../workflow/节点扩展.md)、[执行与存储](../workflow/执行与存储.md)。

## 设计规范

工作流还提供独立 JSON/日期/模板节点、GitHub 原始提交查询、通用 AI 文本生成和通用文本/Markdown 展示，以及独立飞书行查找/矩阵写入；周报只是组合样例，不调用旧周报一体化接口。凭据执行时从 Token 配置读取，不进入工作流端口/导出；飞书每次写入即时确认。独立接口与安全边界见 [原子能力](../workflow-capabilities/README.md)。

工作流独立模块的产品、节点注册和执行/保存边界见 [工作流文档](../workflow/README.md)。画布使用本地打包的 X6，流程定义与图库私有模型分离；原 JSON／ENV 页面保持不变。

页面遵循仓库根目录 `DESIGN.md` 的 `Flat Design Corporativo` 规范：使用蓝色主色、Lato 正文字体、JetBrains Mono 技术标识、8px 间距基准、4/8/12px 圆角层级和轻量阴影。工作流按用户明确要求采用根 `DESIGN.md` 的暗黑局部例外，当前路由的壳层、画布、控件和结果同步暗色，其他页面仍使用浅色；搜索目录与图元复用独立 `--wf-*` 令牌。源项目的深色渐变、强发光、重阴影和独立字体体系未迁移。

## 验证

后端内容对比算法及资源边界的回归测试位于 `apps/system-service/src/__tests__/content-compare*.spec.ts`；比较视图的异步行为由页面测试覆盖。浏览器 Canvas、拖放、响应式和键盘行为仍需通过构建后的页面验收。
