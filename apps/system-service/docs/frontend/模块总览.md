# 前端管理台模块总览

## 目标

前端管理台为 `system-service` 提供统一的工作区入口，采用左侧主导航和右侧主体内容的布局。当前保留工作台总览页面，后续业务页面按实际需求接入，不在静态页面中预先承诺未实现的模块。

## 资源位置

- 源目录：`apps/system-service/public/`
- 页面入口：`/public/index.html`
- 构建目录：`apps/system-service/dist/public/`
- 静态服务：`ServeStaticModule`，挂载路径为 `/public`

`nest-cli.json` 将源目录资源复制到构建目录，页面资源不得在 `src/public` 或其他目录重复维护。

## 页面入口

- `#overview`：工作台总览

无效或未知 hash 会被规范化为 `#overview`，页面不会保留已移除模块的失效入口。

## 设计规范

页面遵循仓库根目录 `DESIGN.md` 的 `Flat Design Corporativo` 规范，使用其中定义的蓝色主色、Lato 字体、8px 间距基准、4/8/12px 圆角层级和轻量阴影。页面不得引入未经设计规范定义的渐变、重阴影或无实际功能的控件。
