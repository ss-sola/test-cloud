# 前端管理台实现逻辑

## 静态服务注册

`apps/system-service/src/app.module.ts` 使用 `ServeStaticModule.forRoot` 注册静态服务：

- `rootPath` 指向编译后的 `dist/public`，通过 `join(__dirname, 'public')` 解析。
- `serveRoot` 为 `/public`，因此入口地址为 `/public/index.html`。
- 公共启动器继续由 `apps/common-service` 提供，`system-service` 不重复配置 Express 中间件。

## 资源构建与脚本兼容

`apps/system-service/nest-cli.json` 在 `compilerOptions.assets` 中配置 `../public/**/*`，将项目根目录下的 `public` 资源复制到 `dist/public`；并开启 `watchAssets` 让开发服务同步静态 fragment。`public` 是唯一源目录，不能手工维护 `dist/public`。

公共自动注册器会扫描构建目录中的 JavaScript 文件并动态加载。`public/js/*.js` 因此使用兼容封装：Node 环境只导出纯逻辑对象，不读取 `document`；浏览器环境再挂载到 `window`。`app.js` 保留 `typeof document` 保护，避免服务启动时执行页面逻辑。

## 页面控制器

`public/js/app.js` 负责：

- 七个合法 hash 的路由规范化：`overview`、`particle`、`json-compare`、`env-compare`、`weekly-report`、`bullmq`、`config-file-preview`。
- 页面 section 不再直接写在入口 HTML 中；`loadViews()` 根据固定路由表加载 `public/html/*.html`，校验单一 `section[data-view]` 后挂入 `#view-host`，并由 `renderRoute()` 继续控制 `hidden`。
- 桌面侧栏折叠、移动端抽屉、遮罩和 Escape 关闭。
- JSON/ENV 共用对比控制器的挂载。
- 周报视图通过 `POST /api/weekly-commit-reports/jobs` 创建任务并轮询 `GET /api/weekly-commit-reports/jobs/status`，直接渲染后端阶段和百分比；终态更新 Markdown、元数据、`projectErrors` 和可选的 `publication` 状态。启用飞书发布时，页面将单个 Wiki/姓名配置传给服务端，服务端固定只读 `A1:B200` 定位日期范围和姓名，再只更新匹配行 C:G 五个工作日单元格；相同内容跳过，发布失败仍保留 Markdown。App Secret 按产品要求保存在页面草稿中，服务端日志边界会脱敏；复制和下载在浏览器内完成。单项目 GitHub 请求失败时，服务端跳过该项目并继续处理。
- BullMQ 面板页面使用 fragment iframe 加载服务端 `/ops/queues/`；面板只读、固定展示 `weekly-report` 队列，使用 `bull` prefix，非 GET 请求在 Express 边界被拒绝。周报任务由 BullMQ Worker 执行并在面板中展示。
- 粒子实验室的文件槽、状态、密度、效果和对象 URL 管理。

页面使用原生 DOM 事件和闭包实例维护状态；周报视图通过服务端 GitHub API 读取提交，不在浏览器中执行命令，也不把 GitHub Token 或 AI 凭据暴露到页面。飞书同步配置仅在用户勾选发布时随 Job 请求发送。

## Fragment 生命周期

`public/html/` 中每个页面只包含一个顶层 `section[data-view]`，入口 `index.html` 只提供 `#view-host`。`app.js` 使用固定的 route-to-file 映射并发加载 fragment，使用 `DOMParser` 校验根节点后导入文档；fragment 文本按 route 缓存在当前页面内，切换时只更新 `hidden`，不重复挂载事件。

配置预览脚本通过 `window.NestCloudConfigFilePreview.mount(root)` 显式挂载，避免脚本早于 fragment 执行。fragment 失败时，`#view-host` 显示文本错误状态；未知路由仍回退到总览。修改 `public/html/*.html` 后由 `watchAssets` 同步到构建目录，浏览器刷新即可读取最新片段。

## 粒子处理链路

- `public/js/image-particles.js` 将本地图像缩放到最长边 900px，使用临时 Canvas 读取像素亮度梯度和透明边界，生成归一化边缘点；粒子上限为 10000。
- `public/js/particle-field.js` 将源 `ParticleField` 改写为可销毁的实例，负责 Canvas 2D、DPR（最大 2）、ResizeObserver、requestAnimationFrame、Pointer Events、A/B 目标和 spring/wave/rotate 过渡。
- 每个素材槽有独立加载版本号，替换素材后旧的异步结果不会覆盖新状态。
- 页面不可见时暂停绘制；`prefers-reduced-motion` 下使用低运动 spring 路径。
- 实例销毁时取消 RAF、断开 ResizeObserver、移除事件和监听器；文件替换/删除时撤销 Object URL。

## JSON/ENV 比较链路

- `public/js/json-diff.js` 保留对象键排序、无身份数组规范化、唯一 `id`/`*Id` 数组身份匹配、嵌套差异树、统计和两侧差异片段序列化。
- `public/js/env-parser.js` 保留 BOM、注释、`export`、引号转义、重复键、行号错误和特殊键安全存储规则，所有值保持字符串。
- `app.js` 中的共用比较控制器负责两侧 textarea、字符数、错误、透明文本层、高亮 `<pre>`、右侧 marker、滚动同步、差异统计和可展开树。
- 输入变化时旧结果被清除；JSON 成功比较后两侧回填规范化 JSON，ENV 成功比较后保留原始 `.env` 文本；错误时均保留原始文本。
- 用户内容和文件名使用 `textContent` 或 textarea value 写入，避免把输入拼入 HTML。
- 周报项目卡片、发布开关和飞书同步配置通过 `nestcloud:weekly-report:v1` 保存到 localStorage，首次挂载优先恢复有效草稿；配置输入变化时即时保存，不迁移旧版 `monthlyTargets`。周报提交时从 Token 配置读取 GitHub Token，随 `runtime.githubToken` 发送。

## 内容扩展

新增业务页面时：

1. 在 `public/html/` 新增与 route 同名的 fragment，保留唯一的 `section[data-view]` 根节点。
2. 在 `index.html` 增加真实的导航链接；不要把业务 section 再放回入口文件。
3. 在 `app.js` 的 fragment 路由表中登记合法 hash、标题和 fragment 路径；需要初始化的页面在 fragment 插入后挂载。
4. 在 `app.css` 中复用现有设计令牌，不散落新的颜色、间距或圆角值。
5. 浏览器专属脚本必须保留 Node 扫描保护，纯逻辑优先提供可测试的 CommonJS 入口。
6. 通过正式接口接入业务数据；本地工具不得伪造网络请求结果。
