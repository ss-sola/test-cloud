# JSON/ENV 对比的实现与边界

## 职责与执行顺序

1. `public/js/app.js` 加载比较页面 fragment 后调用 `window.NestCloudContentCompare.mount(root)`，由 `public/js/content-compare.js` 管理输入、草稿、请求状态和渲染；浏览器不再加载 `public/js/json-diff.js`、`public/js/env-parser.js`，也不在 API 失败时本地重算。
2. 只有用户点击比较或对调 A/B 才向本服务 `POST /api/content-compare/json` 或 `/env` 发送 `{ left, right }`。对调先交换并保存，再发新请求；页面挂载、恢复草稿和普通输入仅在浏览器处理，不上传。
3. 后端受约束 DTO 校验字符串和长度，在请求内由 `JsonCompareUtil`、`EnvParserUtil` 等纯类完成解析、规范化、树、统计与分段计算。服务端不以数据库、文件、session、Redis、进程内状态或外部服务存储/补全本次输入。
4. 前端只使用返回的显示文本、差异树、统计和分段绘制双侧编辑器、高亮 marker 与折叠树，保留滚动同步。JSON 成功后以分段拼接文本回填，ENV 不回填规范化文本；原文及草稿在浏览器 localStorage 的 `nestcloud:compare:json:v1` 和 `nestcloud:compare:env:v1`，键与原有格式保持不变。

## 兼容规则

- JSON 对象键按既有规则排序。对象数组通过唯一的 `id` 或 `*Id` 字段匹配，以值及其类型共同识别身份（数字 `1` 与字符串 `"1"` 不同）；普通数组按规范化顺序比较。新增、删除相对于左侧 A / 右侧 B 定向，不因排序导致方向颠倒。保留嵌套差异树统计；特殊键 `__proto__`、`constructor` 按普通数据键安全处理，不写入对象原型。
- 普通标识符键使用 `.key` 路径，其余键使用 JSON 字符串括号形式，例如顶层 `"a.b"` 为 `$["a.b"]`，与嵌套 `$.a.b`、数组下标 `[0]` 和身份数组路径互不混淆。路径限额按转义后的实际长度检查，折叠状态按唯一节点路径维护。
- JSON 格式选择在写分段前通过有界遍历计算长度。默认两空格缩进，超过每侧 500000 字符时改用紧凑格式；紧凑格式仍超限则受控返回 413。成功文本一定可再次提交和保存草稿，孤立代理项转义导致的长度膨胀也受此约束。
- ENV 支持 BOM 和 CRLF、CR、LF 换行、空行/注释、`export` 前缀、引号与指定转义、行尾注释、空值和重复键先前行号；键值始终是字符串，不执行命令、变量展开或类型转换。兼容以 JSON 对象形式输入 ENV；这种输入仍显示原始文本、返回未标色原文片段。
- JSON `segments` 按侧拼接必须与规范化 `leftText`/`rightText` 一致，ENV `segments` 按侧拼接必须与原文一致。数字键的展示文本由分段拼接，避免前端再次格式化产生错位。公开树节点仅包含 `key/path/hasLeft/hasRight/type/status/leftDisplay/rightDisplay/children`；容器的左右 display 按自身类型给出计数，不包含整个子树序列化内容，即使另一侧是标量也不展开子树。

## 资源和隐私

- 每侧 500000 UTF-16 字符、结构深度 64、节点 10000；最长路径 4096 字符、每侧最多 100 条解析错误；比较路由 JSON 请求体最多 6 MiB、结果最多 8 MiB。输入解析后先迭代检查结构，再进入递归差异计算；构建路径、显示值及分段时维护保守输出预算，可提前返回受控 400/413，不等待最终序列化耗尽资源。
- 只在 `system-service` 为两个比较路由设置专用 JSON parser、`Cache-Control: no-store` 与错误转换；不改 `common-service` 或其他路由的日志。专用边界提前拒绝错误方法、未知子路径及不支持的 Content-Type；响应完成前清除比较请求的 `req.body`，使公共访问日志不记录原文。专用异常处理不调用可能记录 body/异常栈的公共错误过滤器；错误日志仅写固定状态信息，验证异常及解析错误响应不得带原文片段、键值或校验 value/target。
- 原文会从浏览器发送到本服务，因此不要称其为离线/纯本地对比；后端不持久化、不缓存、不外发输入与结果。`no-store` 限制 HTTP 缓存，不等于阻止当前浏览器在上述既有 localStorage 键中保存草稿。图片转粒子仍只在浏览器本地处理，不上传图片。
- 请求进行中显示忙碌状态与 `aria-busy`。编辑立即清除旧结果并取消请求；重复比较、对调、错误或超时后，用 AbortController 和请求代次拦截迟到的成功/失败响应，只有当前请求能修改错误或忙碌状态。30 秒前端超时后可重试，失败保留输入，不在浏览器回退到旧算法。

请求/响应字段与状态码详见 [API](./API.md)，页面行为详见 [前端交互](../frontend/前端交互.md)。
