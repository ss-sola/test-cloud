# 论文查重算法验证测试

## 1. 测试目的

验证当前论文查重算法是否真正实现：

```text
重复内容检测
```

而不是：

```text
全文相似度计算
```

本测试不使用：

- Embedding
- 向量数据库
- LLM
- 语义模型

重点验证：

- 完全重复文本
- 局部连续重复
- 部分改写
- 语义相似但文字不同
- 短文本误报
- 重复片段合并
- 重复片段重叠
- 重复率计算
- 双向查重

---

# 2. 查重判定标准

建议第一版使用：

```text
最小连续重复长度：8 个字符
```

只有连续重复长度 >= 8 的文本，才进入最终重复片段。

例如：

```text
人工智能
```

长度只有 4：

```text
不算重复
```

而：

```text
人工智能技术的发展
```

长度超过 8：

```text
可以算重复
```

# 3. 测试用例一：完全重复

## Text A

```text
人工智能技术正在快速改变现代教育的发展方式。教师可以利用人工智能分析学生的学习情况，并根据不同学生的知识掌握程度制定合理的教学方案。
```

## Text B

```text
人工智能技术正在快速改变现代教育的发展方式。教师可以利用人工智能分析学生的学习情况，并根据不同学生的知识掌握程度制定合理的教学方案。
```

## 预期结果

应该识别为：

```text
100% 重复
```

A 中：

```text
【人工智能技术正在快速改变现代教育的发展方式】
【教师可以利用人工智能分析学生的学习情况，并根据不同学生的知识掌握程度制定合理的教学方案】
```

B 中同样全部高亮。

预期：

```text
duplicateRate = 100%
```

# 4. 测试用例二：前半部分重复，后半部分不同

## Text A

```text
人工智能技术正在快速改变现代教育的发展方式。教师可以利用人工智能分析学生的学习情况，并根据不同学生的知识掌握程度制定合理的教学方案。传统课堂通常采用统一的教学内容和教学进度。
```

## Text B

```text
人工智能技术正在快速改变现代教育的发展方式。教师可以利用人工智能分析学生的学习情况。随着在线教育平台不断发展，学生可以通过网络获得更加丰富的学习资源。
```

## 预期高亮

A：

```text
【人工智能技术正在快速改变现代教育的发展方式】
【教师可以利用人工智能分析学生的学习情况】
，并根据不同学生的知识掌握程度制定合理的教学方案。传统课堂通常采用统一的教学内容和教学进度。
```

B：

```text
【人工智能技术正在快速改变现代教育的发展方式】
【教师可以利用人工智能分析学生的学习情况】
。随着在线教育平台不断发展，学生可以通过网络获得更加丰富的学习资源。
```

注意：

```text
“并根据不同学生的知识掌握程度制定合理的教学方案”
```

没有出现在 B 中，因此不能高亮。

# 5. 测试用例三：中间出现重复

## Text A

```text
随着信息技术不断发展，人工智能已经逐渐进入教育领域。教师可以利用人工智能分析学生的学习情况，从而了解学生的知识掌握程度。通过分析学生的答题记录和错误类型，教师能够制定更加合理的教学方案。
```

## Text B

```text
近年来在线教育发展迅速。教师可以利用人工智能分析学生的学习情况，从而了解学生的知识掌握程度。智能教育平台还可以根据学生的学习表现推荐相关课程。
```

## 预期高亮

A：

```text
随着信息技术不断发展，人工智能已经逐渐进入教育领域。

【教师可以利用人工智能分析学生的学习情况，从而了解学生的知识掌握程度】

通过分析学生的答题记录和错误类型，教师能够制定更加合理的教学方案。
```

B：

```text
近年来在线教育发展迅速。

【教师可以利用人工智能分析学生的学习情况，从而了解学生的知识掌握程度】

智能教育平台还可以根据学生的学习表现推荐相关课程。
```

重点：

```text
前面的内容不同
后面的内容不同
只有中间连续文本重复
```

如果程序把整篇判成高度重复：

```text
❌ 算法错误
```

# 6. 测试用例四：语义相似但文字不同

## Text A

```text
人工智能正在改变传统教育模式，教师可以利用智能系统了解学生的学习情况，并针对不同学生制定个性化的教学计划。
```

## Text B

```text
随着智能技术的发展，学校开始采用新的教学方式。系统能够分析学生的学习数据，并帮助教师为不同学习水平的学生安排合适的课程。
```

## 预期结果

两段文本：

```text
主题相同
语义相近
表达方式不同
```

因此：

```text
duplicateRate ≈ 0%
```

不应该出现大面积高亮。

如果你的程序返回：

```text
similarity = 80%
duplicateRate = 80%
```

说明：

```text
❌ 把语义相似当成了论文重复
```

# 7. 测试用例五：少量文字重复

## Text A

```text
人工智能可以帮助教师分析学生的学习情况，并提高教学效率。
```

## Text B

```text
教师需要关注学生的学习情况，并通过合理的方法提高教学效率。
```

共同内容包括：

```text
学生的学习情况
提高教学效率
```

但是每个连续片段较短。

如果：

```text
minDuplicateLength = 8
```

应该根据实际字符长度判断。

预期：

```text
不应该把“学生”“学习情况”等短词单独高亮。
```

# 8. 测试用例六：重复片段中间存在不同文字

## Text A

```text
人工智能技术正在快速改变现代教育的发展方式，并推动在线教育平台不断发展。
```

## Text B

```text
人工智能技术正在快速改变现代教育的发展方式，同时推动智能教学系统不断完善。
```

## 预期

应该高亮：

```text
【人工智能技术正在快速改变现代教育的发展方式】
```

不应该高亮：

```text
并推动在线教育平台不断发展
```

也不应该因为：

```text
推动
```

相同而把后半部分标红。

# 9. 测试用例七：重复片段相邻

## Text A

```text
人工智能正在改变现代教育。人工智能能够分析学生数据。人工智能还可以推荐学习资源。
```

## Text B

```text
人工智能正在改变现代教育。人工智能能够分析学生数据。人工智能还可以推荐学习资源。
```

## 预期

三个重复区域：

```text
【人工智能正在改变现代教育】
【人工智能能够分析学生数据】
【人工智能还可以推荐学习资源】
```

如果三个区域之间距离非常小，可以合并为一个连续重复区间。

# 10. 测试用例八：重复区间重叠

## Text A

```text
人工智能技术正在改变现代教育的发展模式。
```

## Text B

```text
人工智能技术正在改变现代教育的发展模式。
```

算法可能得到：

```text
[0, 10]
[5, 15]
[8, 20]
```

这些区间发生重叠。

最终必须合并：

```text
[0, 20]
```

不能计算：

```text
10 + 10 + 12
```

否则重复率会超过真实值。

# 11. 测试用例九：相同文字但顺序不同

## Text A

```text
人工智能可以分析学生的学习情况，并根据分析结果推荐学习资源。
```

## Text B

```text
系统可以推荐学习资源，并利用人工智能分析学生的学习情况。
```

两个文本包含大量相同词汇。

但是顺序发生变化。

预期：

```text
不应该因为词语集合高度相似，就认为整段文字重复。
```

可以存在局部高亮：

```text
【分析学生的学习情况】
【推荐学习资源】
```

但不能把整句判定为重复。

# 12. 测试用例十：插入少量文字

## Text A

```text
人工智能技术正在快速改变现代教育的发展方式。
```

## Text B

```text
当前人工智能技术正在快速改变现代教育的发展方式。
```

预期：

A：

```text
【人工智能技术正在快速改变现代教育的发展方式】
```

B：

```text
当前【人工智能技术正在快速改变现代教育的发展方式】
```

即使前面插入：

```text
当前
```

也不应该导致整个重复片段无法识别。

# 13. 测试用例十一：删除少量文字

## Text A

```text
人工智能技术正在快速改变现代教育的发展方式。
```

## Text B

```text
人工智能技术正在改变现代教育的发展方式。
```

两者只有：

```text
“快速”
```

被删除。

如果算法支持近似连续匹配，可以识别为：

```text
高度重复
```

但不要直接把：

```text
Jaccard = 95%
```

当作：

```text
duplicateRate = 95%
```

应该通过重复区间确认具体重复内容。

# 15. 核心验收标准

实现完成后，至少满足：

| 测试         | 预期               |
| ------------ | ------------------ |
| 完全相同     | 接近 100% 重复     |
| 部分连续重复 | 只高亮重复部分     |
| 前后内容不同 | 不影响重复片段检测 |
| 语义相似     | 不应大量高亮       |
| 单个相同词   | 不应高亮           |
| 多个相同短词 | 不应大量高亮       |
| 顺序不同     | 不应判定整段重复   |
| 插入少量文字 | 仍能识别重复       |
| 删除少量文字 | 能识别高度重复     |
| 重复区间重叠 | 必须合并           |
| 完全不同     | 0% 重复            |

# 16. 最重要的验收指标

最终接口至少返回：

```ts
interface PlagiarismResult {
  duplicateRate: number;

  duplicateLength: number;

  sourceLength: number;

  targetLength: number;

  matches: PlagiarismMatch[];

  similarity?: number;
}
```

其中：

```text
duplicateRate
```

是**查重核心指标**。

```text
matches
```

是**高亮核心数据**。

```text
similarity
```

只能作为辅助指标。

# 17. 前端高亮验证

最终前端应该能够得到：

```text
原文：

人工智能技术正在快速改变现代教育的发展方式。
教师可以利用人工智能分析学生的学习情况。
传统课堂通常采用统一的教学内容。

```

渲染为：

```text
【人工智能技术正在快速改变现代教育的发展方式】
【教师可以利用人工智能分析学生的学习情况】
传统课堂通常采用统一的教学内容。
```

其中：

```text
【红色区域】
```

代表重复内容。

而不是：

```text
整篇文章红色
```

# 18. 双向查重

建议接口同时计算：

```text
A → B
B → A
```

因为：

```text
A = 1000 字
B = 500 字
```

如果 B 的 400 字全部出现在 A 中：

```text
B → A = 80%
```

但是：

```text
A → B = 40%
```

两者完全不同。

因此最终返回：

```ts
interface BidirectionalPlagiarismResult {
  sourceToTarget: PlagiarismResult;

  targetToSource: PlagiarismResult;
}
```

这样前端可以明确展示：

```text
A 与 B 的重复情况

A → B：40%
B → A：80%
```

而不是强行压成一个神秘的：

```text
60%
```

# 19. 最终算法原则

整个查重系统应该遵循：

```text
相似度 ≠ 查重率
```

具体：

```text
Jaccard
    ↓
判断文本整体是否相似

SimHash
    ↓
判断文本整体是否接近

LCS / Common Substring
    ↓
寻找具体重复内容

重复区间合并
    ↓
防止重复计算

重复字符数 / 总字符数
    ↓
真正的 duplicateRate
```

最终目标不是回答：

> “这两篇文章像不像？”

而是回答：

> “这篇文章中有多少内容可以在另一篇文章中找到，以及具体是哪一些内容？”
