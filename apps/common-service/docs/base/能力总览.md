# Base 能力总览

## 职责

`base` 目录提供实体、服务、仓储的标准化基类，是所有业务实体的统一起点。

## 核心组件

### BaseEntity

- 位置：`src/base/base.entity.ts`
- 提供统一字段：`id`、`createUser`、`updateUser`、`createdAt`、`updatedAt`、`deletedAt`
- 所有实体必须继承 `BaseEntity`

### BaseService

- 位置：`src/base/base.service.ts`
- 继承方提供统一 CRUD：`findAll`、`findOne`、`create`、`update`、`delete`、`paginate`
- 自动审计字段注入（`applyCreateAudit`、`applyUpdateAudit`）
- 分页返回字段统一为 `list`（非 `items`）

### BaseController

- 位置：`src/base/base.controller.ts`
- 继承方提供标准路由：`GET` 列表、`GET/:id` 详情、`POST` 创建、`PUT/:id` 更新、`DELETE/:id` 删除
- 统一使用 `ResponseUtil.success` 包裹返回值

## 使用约束

- 实体类必须继承 `BaseEntity`
- 实体对应的 service 必须继承 `BaseService`
- 实体对应的 controller 必须继承 `BaseController`
- 非实体类的 service（如 `*Service`）和 controller 不受此约束
