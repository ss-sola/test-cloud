# 日志能力总览

## 职责

公共日志实现统一承载服务日志输出，不允许业务代码直接使用 `console`。

## 核心实现

- `apps/common-service/src/logger/logger.service.ts`

## 当前特征

- 基于 winston 创建日志实例
- 控制台日志级别通过配置解析
- 默认非生产环境开启控制台输出
- 捕获未处理 Promise 异常与未捕获异常
- `AppLogger` 通过 Nest DI 提供单例入口，启动流程改为从容器获取后挂到 `app.useLogger()`，避免重复注册进程级异常监听
- 错误对象输出会展开 `name`、`message`、`stack` 与 `cause`，避免启动失败等场景只打印 `{}`
