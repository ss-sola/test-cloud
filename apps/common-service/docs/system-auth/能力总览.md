# System Auth 能力

## 职责

提供统一的认证与权限校验能力，包括登录态验证、权限守卫、当前账号注入。

## 核心组件

### SessionAuthGuard

- 位置：`src/system-auth/auth/session-auth.guard.ts`
- 验证 express-session 是否有效，放行已登录请求

### PermissionGuard

- 位置：`src/system-auth/auth/permission.guard.ts`
- 校验 `req.currentAccount.permissionCodes` 是否包含所需权限
- 支持 ALL（全部满足）和 ANY（任一满足）两种匹配模式

### CurrentAccountMiddleware

- 位置：`src/system-auth/auth/current-account.middleware.ts`
- 从 session 中提取 `account` 信息并注入 `req.currentAccount`
- 避免 Guard 重复读取 session

### 装饰器

- `@RequirePermissions`：方法级权限要求
- `@RequireAnyPermissions`：方法级任一权限要求
- 也可标注在类上，作用于该类所有方法

## 请求上下文

| 字段 | 类型 | 说明 |
|------|------|------|
| `req.currentAccount` | `AccountSessionPayload` | 当前登录账号信息 |
| `req.currentAccount.accountId` | `number` | 账号 ID |
| `req.currentAccount.accountName` | `string` | 账号名 |
| `req.currentAccount.displayName` | `string` | 显示名 |
| `req.currentAccount.permissionCodes` | `string[]` | 权限码列表 |

## 使用约束

- Guard 只做登录放行判断，`req.currentAccount` 注入放到中间件
- 子项目不自建业务 `Module` 类，通过自动扫描注册 Controller 和 Provider
