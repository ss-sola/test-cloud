# HTTP 远程调用能力

## 职责

提供跨服务 HTTP 远程调用的标准化机制，支持服务发现、负载均衡、超时控制。

## 核心组件

### RemoteClientBase

- 位置：`src/http/remote-client.base.ts`
- 所有远程调用客户端的基类
- 通过 Proxy 拦截方法调用，自动拼接 URL、转发 Header、处理负载均衡

### @RemoteService

- 位置：`src/http/remote-service.decorator.ts`
- 标注在 `RemoteClientBase` 子类上，声明服务名、固定 URL、负载均衡策略

### @RemoteCall

- 位置：`src/http/remote-call.decorator.ts`
- 标注在方法上，声明 HTTP 路径和方法（GET/POST/PUT/DELETE）

### 负载均衡策略

| 策略 | 类 | 说明 |
|------|------|------|
| 随机 | `RandomStrategy` | 随机选择一个实例 |
| 轮询 | `RoundRobinStrategy` | 轮流选择实例 |
| 加权 | `WeightedStrategy` | 按权重分配 |

## 使用方式

```typescript
@RemoteService({ name: 'system-service' })
class SystemServiceClient extends RemoteClientBase {
  @RemoteCall('/api/system/accounts/list', 'GET')
  listAccounts(query: Record<string, string>): Promise<any> {}
}
```

## 约束

- 跨服务调用必须使用 `RemoteClientBase` 继承类，禁止直接使用 `fetch`/`axios`
- `@RemoteCall` 装饰器中的路径直接使用字符串，不需要提取为常量
- 默认超时由 `DEFAULT_REMOTE_TIMEOUT` 配置
- 生产环境优先使用注册中心发现实例，非生产可配置固定 URL
