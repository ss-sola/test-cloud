# Redis Session 能力

## 职责

提供基于 Redis 的分布式 Session 存储，支持多服务共享登录态。

## 核心实现

- `createRedisSession()`：创建 express-session 中间件
- `RedisSessionStore`：实现 express-session Store 接口的 Redis 存储

## 配置项

| 配置键 | 说明 | 默认值 |
|--------|------|--------|
| `SessionRedisUrl` | Redis 连接 URL | 不配则降级为内存存储 |
| `SessionSecret` | Cookie 签名密钥 | 必填 |
| `SessionCookieName` | Cookie 名称 | `system.sid` |
| `SessionTtlMs` | 会话有效期（毫秒） | 8 小时 |
| `SessionKeyPrefix` | Redis key 前缀 | `system-session` |
| `SessionSameSite` | SameSite 策略 | `lax` |
| `SessionSecure` | HTTPS-only cookie | `false` |

## 特性

- **降级策略**：未配置 `SessionRedisUrl` 时自动降级为 `MemoryStore`
- **滚动过期**：每次请求自动延长会话有效期
- **权限热更新**：通过 `updateAccountPermissions` / `updateMultipleAccountsPermissions` 实时刷新所有 session 中的权限码
- **角色账户索引**：通过 Redis Set 维护 `role:{code}:accounts` 索引，支持按角色批量查询

## 隔离策略

- 多服务共用同一 Redis 时，通过 `SessionKeyPrefix` 隔离 key 空间
- Cluster 模式下不支持 DB 隔离，必须使用 prefix
