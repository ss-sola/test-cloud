# 配置中心接入能力总览

## 职责

配置中心公共能力负责：

- 加载本地配置文件
- 在启用时拉取远程配置
- 合并远程配置与本地开发配置
- 通过 `getConfig` 与 `validateConfig` 对外提供统一读取方式
- `getConfig` 支持按默认值类型或显式类型参数做运行时转换

## 核心实现

- `apps/common-service/src/config-center/index.ts`

## 协作边界

- 这里只描述客户端侧配置接入能力
- 配置文件的草稿、发布、版本归档由 `config-service` 服务端能力负责
- 配置拉取协议、合并规则或默认行为变化时，需要同步更新根级 `docs/project/配置中心与注册中心.md`
