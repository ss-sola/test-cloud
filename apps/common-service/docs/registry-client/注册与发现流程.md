# 注册与发现流程

## 注册

应用启动完成后，客户端会向注册中心发起实例注册：

- `POST {registryUrl}/api/registry/register`

## 心跳

注册成功后，客户端按固定间隔发送心跳：

- `POST {registryUrl}/api/registry/heartbeat/{instanceId}`

若发现实例不存在，会停止当前心跳并重新走注册流程。

## 本地缓存

客户端会定时同步：

- `GET {registryUrl}/api/registry/all`

同步结果保存在本地缓存，用于后续服务发现。

## 使用约束

- 当注册中心地址指向当前服务自身时，客户端不会重复注册自己
- 服务发现优先读取本地缓存，不直接在业务层拼接注册中心请求
- 注册、心跳、发现接口变化时，应同步更新根级 `docs/project/配置中心与注册中心.md`
